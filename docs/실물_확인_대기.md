## 0. 먼저 · 갱신 전에 알아 둘 것

- **단위가 rad 로 바뀌었다**(수정 목록 6) · main 을 받은 PC 는 토픽·매핑·재생 안쪽이 rad · 화면은 그대로 deg
  - `install.sh` 가 C++(motor_manager 노드)도 다시 빌드한다 · 빌드 실패면 거기서 멈추고 기록
  - 조인트 매핑 파일은 처음 **저장할 때** rad 칸 + deg 사본으로 바뀐다 · 옛 버전으로 되돌려도 deg 사본을 읽는다
  - 애니메이션 파일은 rad·deg·칸 없음(=deg) 모두 같은 크기로 재생된다
  - 모터 설정 파일 · 로봇 팩 · 재생 기록 CSV 는 deg 그대로
- 여러 PC 연동은 **모든 PC 를 같은 버전으로** 갱신(메시지 약속 번호 **5** · 2026-10-07 · 스피커 PC 포함 · 수정 목록 30-7 · 30-3 · 38)
- **모터 켜기 전에 · 우분투 PC 에서 자동 테스트부터**(수정 목록 10) · 윈도우 개발 PC 에는 ROS 가 없어 `rclpy`·메시지 쓰는 테스트 37건은 못 돌렸고 · C++(motor_manager)는 문법 검사만 했다 · 엣지 케이스(알람 중 명령 · 그룹 복귀 타이밍 · 늦은 이벤트 · 끊긴 축 등)는 대부분 이 테스트가 잡는다
  - `install.sh` 의 `colcon build` 통과 → `source install/setup.bash` → 저장소 맨 위에서 `pytest` · `node --test src/web_ui/test/` · 실패 0 이면 아래로 · 실패면 기록하고 멈춤
  - 실물로는 테스트가 못 잡는 것(실제 드라이브 응답 · 타이밍 · Wi-Fi · 기구)만 본다 · 위험한 것(랜선 분리 · 알람 유발)은 저속 애니메이션으로
