# 실물 확인 대기 · 코드는 main 에 들어갔고 실물로 아직 못 본 것

- 작성 · 2026-10-06 · 기준 커밋 · 이 문서가 들어간 main
- 쓰는 법 · 실물 앞에서 위에서부터 한다 · 결과는 `확인됨` · `실패` · `검증 불가` 로만 적는다(`AGENTS.md`) ·
  끝난 줄은 `docs/수정_목록.md` 그 항목 상태란에 옮기고 여기서 지운다
- 전체 흐름(설치 → 팩 → 수동 → 재생 → 스케줄 → 연동)은 `실물_검증_계획.md` · 이 문서는 **그 뒤에 바뀐 것만**
- 모터가 움직이는 단계는 사람이 옆에 있고 비상정지가 손에 닿을 때만

## 0. 먼저 · 갱신 전에 알아 둘 것

- **단위가 rad 로 바뀌었다**(수정 목록 6) · main 을 받은 PC 는 토픽·매핑·재생 안쪽이 rad · 화면은 그대로 deg
  - `install.sh` 가 C++(motor_manager 노드)도 다시 빌드한다 · 빌드 실패면 거기서 멈추고 기록
  - 조인트 매핑 파일은 처음 **저장할 때** rad 칸 + deg 사본으로 바뀐다 · 옛 버전으로 되돌려도 deg 사본을 읽는다
  - 애니메이션 파일은 rad·deg·칸 없음(=deg) 모두 같은 크기로 재생된다
  - 모터 설정 파일 · 로봇 팩 · 재생 기록 CSV 는 deg 그대로
- 여러 PC 연동은 **모든 PC 를 같은 버전으로** 갱신(메시지 약속 번호 3 · 수정 목록 30-7)
