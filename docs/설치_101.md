# 설치 101 · 우분투만 깔린 PC 에서 전시 준비까지

**전제** · PC 마다 Ubuntu 데스크톱이 깔려 있고(이 브랜치 `jazzy` = 24.04 · 22.04 는 `humble` 브랜치 주소로 · 한 그룹은 모두 같은 브랜치), 늘 쓸 계정 하나로 로그인할 수 있고, 인터넷이 된다.
**대상** · 로봇 PC 4대(floating1 ~ floating4) · 스피커 PC 1대 · 같은 공유기.
**표시** · 👤 = 사람이 직접 해야 하는 일(스크립트가 못 함) · 나머지는 명령 한 줄이 한다.

자세한 설명은 README 「새 PC 설치」 · 화면 쓰는 법은 `docs/사용법.md` · 스피커는 `speaker_app/README.md`.

## 1. 👤 BIOS · 모든 PC (한 번)

부팅 화면에서 `Del` 또는 `F2` 로 BIOS 에 들어간다 · 이름은 메인보드마다 조금씩 다르다.

| 찾을 이름 | 값 | 왜 | 대상 |
|---|---|---|---|
| `Restore on AC Power Loss` / `AC Back` / `After Power Failure` | **Power On** | 전원을 넣거나 정전 뒤 사람 없이 켜지게 | 모든 PC |
| `Secure Boot` | **Disabled** | 켜져 있으면 직접 빌드한 EtherCAT 커널 모듈(서명 없음)이 안 올라가 AC 서보가 안 된다 | 로봇 PC |

**확인** · 전원 케이블을 뽑았다 꽂으면 저절로 켜진다 · 로봇 PC 설치 끝 자가 점검표에 `Secure Boot 꺼짐 [OK]`.

## 2. 로봇 PC (floating1 ~ 4) · PC 마다

### 2-1. 👤 랜선

- **인터넷(공유기)** 은 Wi-Fi 또는 유선 포트 하나
- **모터(EtherCAT)** 랜선은 **다른 유선 포트** → 드라이브 · 설치가 「IP 없는 유선 포트」를 모터 포트로 고른다 ·
  그래서 모터 포트에는 공유기를 꽂지 않는다 · 유선 포트가 둘 이상 비어 있으면 설치 중에 묻는다

### 2-2. 한 줄 설치

터미널(`Ctrl+Alt+T`)에

```bash
curl -fsSL https://raw.githubusercontent.com/y0ung-GMLAB/robot_web/jazzy/scripts/bootstrap.sh | bash
```

- 컴퓨터 이름(`hostname`)이 그대로 `PC ID` 가 된다 · 웹에서는 못 바꾼다 · 이름이 틀렸으면 끝에 `-s -- --name floating1` 을 붙여 바꾸며 설치
- **옛 스택(kimjoonho motion_web)이 깔린 PC** · 그냥 치면 「`~/ros2_ws` 에 다른 프로그램이 있습니다」 로 멈춘다 ·
  끝에 `-s -- --replace-old` 를 붙여 다시(이름도 바꾸면 `-s -- --replace-old --name floating1`) ·
  옛 서비스를 멈추고 옛 폴더를 `~/ros2_ws_old_<날짜>` 로 옮긴 뒤(지우지 않음) 새로 깐다 ·
  옛 매핑·기준점·모터 설정은 안 옮겨지니 2-3 을 처음부터 · 옛 애니메이션 `.json` 은 옛 폴더 `motion_projects/` 에서 꺼내 다시 올리면 된다 ·
  그룹 PC 는 전부 새 스택이어야 붙는다 · 자세히 README 「옛 스택이 깔린 PC」

- 👤 sudo 비밀번호 1회 · 시간대 질문 1회(Enter = 지금 값) · 모터 랜카드가 둘 이상이면 고르기
- 나머지는 저절로 · 자동 업데이트·절전·화면 잠금 끄기 · 자동 로그인 · 로그아웃해도 유지 · 방화벽 같은 망 허용 ·
  EtherLab 설치 · 모터 랜카드 설정 · 코드 받기(`~/ros2_ws`) · 빌드 · 서비스 등록
- 중간에 **스스로 재부팅 1회** → 자동 로그인 → 저절로 이어서 끝 (몇 분) · 끝에 자가 점검표
- 점검표에 `[확인]` 이 있으면 그 줄만 본다 · 실시간 권한은 재부팅 뒤 적용

### 2-3. 👤 웹 화면에서 (그 PC 브라우저 `http://localhost:8000/v2` · 또는 다른 PC 에서 `http://floating<n>.local:8000/v2` · 안 되면 `http://<IP>:8000/v2`)

### 5-1. 👤 EtherCAT 커널 모듈 갱신 · 로봇 PC 마다 sudo 한 번 (수정 목록 139 · 2026-10-14)

IgH 패치(SDO 사전 자동 읽기 끄기 · `sdo_dict=0`)는 **커널 모듈**이라 웹 `모든 PC 업데이트`(`install.sh --code-only` · 관리자 권한 없음)로는 안 바뀐다.
코드를 먼저 올린 뒤 **각 로봇 PC 에서** (자세히 `docs/수정_139_IgH_패치.md` F)

1. 모터 정지 확인 (재생·조그 없음) · 서보 오프
2. `bash ~/ros2_ws/scripts/install.sh --site` · EtherLab 단계가 **커널 모듈만** 다시 빌드한다(이미 깔린 CLI·라이브러리·서비스는 그대로 · PC 마다 깔린 자리가 달라서 `make install` 안 함) ·
   패치 파일을 `/usr/local/share/robot_web/` 에 두고 커널 재빌드 서비스(`ethercat-rebuild`)도 깐다 ·
   그 PC 의 `ethercat.conf` 가 `DEVICE_MODULES="generic"` 이 아니거나 깔린 IgH 가 1.6.9 가 아니면 **멈춘다**(손으로)
   - 재빌드 서비스가 이미 깔린 PC 는 `sudo /usr/local/sbin/ethercat-rebuild --force` 로도 된다(모듈만)
3. `systemctl --user stop motion-motor.service` (모터 프로그램이 마스터를 잡고 있으면 모듈을 못 내린다)
4. `sudo systemctl restart ethercat` (ethercatctl 이 옛 모듈을 내리고 새 모듈을 올린다)
5. 확인 · `modinfo -p ec_master | grep sdo_dict` 줄 있음 · `cat /sys/module/ec_master/parameters/sdo_dict` = `0` · `ethercat slaves` 에 드라이브 다 보임
6. `systemctl --user start motion-motor.service` · 웹에서 드라이브 OP · 앱솔루트 정상 · `check.sh` 의 「EtherCAT SDO 사전 읽기 꺼짐」 `[OK]`

되돌리기 · 다시 빌드 없이 `echo 1 | sudo tee /sys/module/ec_master/parameters/sdo_dict` (다음 재스캔부터 원래대로)

## 6. 설치 확인 · PC 마다 한 줄

바꾸는 것 없이 읽기만 한다 · 몇 번 쳐도 된다 · 로봇 PC 인지 스피커 PC 인지 스스로 가린다.

| PC | 명령 |
|---|---|
| 로봇 PC | `bash ~/ros2_ws/scripts/check.sh` |
| 스피커 PC | `bash ~/robot_web/scripts/check.sh` |

`[OK]` · `[확인]` · `[정보]` 로 한 줄씩 찍고 끝에 `결과 · 모두 OK` 또는 `[확인] N개` · `[확인]` 줄 끝의 안내대로 하고 다시 친다.

| 보는 것 | 로봇 PC | 스피커 PC |
|---|---|---|
| 공통 | 공유기 IP · 코드가 최신 main · linger · 자동 업데이트 꺼짐 · 시간대 | 같음 |
| 설치 | 자동 로그인 · 실시간 권한 · Secure Boot 꺼짐 · 서비스 3개 · EtherCAT · 드라이브 수 · SDO 사전 읽기 꺼짐(139) | speaker-app · 그룹 메시지 빌드 |
| 화면 | 웹 `:8000` (새 화면 `:8000/v2`) · 앱솔루트 경고 없음 | 스피커 화면 `:8100` |
| 연동 | 이 PC ID = 컴퓨터 이름 · 연동 사용 · 그룹 · Domain · 그룹 참가 · **같은 망 PC 목록(끊김 · 버전 다름 표시)** | 연동 모드 · DDS 시작 · 로봇 PC 신호 · 그룹 · 이름 |
| 소리 | | 음원 수 · 기본 음원 · 출력 장치가 실제로 있음 |

- `motion-motor` 는 모터 설정을 「장비에 적용」 하기 전이면 꺼져 있는 게 정상이다(모터가 멋대로 돌지 않게)
- **전체 확인은 마스터에서** · 마스터의 `같은 망 PC` 줄에 나머지 4대(로봇 3 + 스피커 1)가 모두 `[OK]` 면 5대 연결 · 버전이 같다
- 스크립트가 못 보는 것(👤) · BIOS 전원 복구(전원 뽑았다 꽂기) · 실제 소리 · 모터 움직임(튐 · 처짐)
