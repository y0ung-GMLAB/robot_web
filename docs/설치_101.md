# 설치 101 · 우분투만 깔린 PC 에서 전시 준비까지

**전제** · PC 마다 Ubuntu 22.04 데스크톱이 깔려 있고, 늘 쓸 계정 하나로 로그인할 수 있고, 인터넷이 된다.
**대상** · 로봇 PC 4대(floating1 ~ floating4) · 스피커 PC 1대 · 같은 공유기.
**표시** · 👤 = 사람이 직접 해야 하는 일(스크립트가 못 함) · 나머지는 명령 한 줄이 한다.

자세한 설명은 README 「새 PC 설치」 · 화면 쓰는 법은 `docs/사용법.md` · 스피커는 `speaker_app/README.md`.

## 1. 👤 BIOS · 모든 PC (한 번)

부팅 화면에서 `Del` 또는 `F2` 로 BIOS 에 들어간다 · 이름은 메인보드마다 조금씩 다르다.

| 찾을 이름 | 값 | 왜 | 대상 |
|---|---|---|---|
| `Restore on AC Power Loss` / `AC Back` / `After Power Failure` | **Power On** | 전원을 넣거나 정전 뒤 사람 없이 켜지게 | 모든 PC |
| `Secure Boot` | **Disabled** | 켜져 있으면 직접 빌드한 EtherCAT 커널 모듈(서명 없음)이 안 올라가 AC 서보가 안 된다 | 로봇 PC |

**확인** · 전원 케이블을 뽑았다 꽂으면 저절로 켜진다 · 로봇 PC 설치 끝 자가 점검표에 `Secure Boot 꺼짐 [OK]`.

## 2. 로봇 PC (floating1 ~ 4) · PC 마다

### 2-1. 👤 랜선

- **인터넷(공유기)** 은 Wi-Fi 또는 유선 포트 하나
- **모터(EtherCAT)** 랜선은 **다른 유선 포트** → 드라이브 · 설치가 「IP 없는 유선 포트」를 모터 포트로 고른다 ·
  그래서 모터 포트에는 공유기를 꽂지 않는다 · 유선 포트가 둘 이상 비어 있으면 설치 중에 묻는다

### 2-2. 한 줄 설치

터미널(`Ctrl+Alt+T`)에

```bash
curl -fsSL https://raw.githubusercontent.com/y0ung-GMLAB/robot_web/main/scripts/bootstrap.sh | bash
```

- 컴퓨터 이름(`hostname`)이 그대로 `이 PC ID` 가 된다 · 웹에서는 못 바꾼다 · 이름이 틀렸으면 끝에 `-s -- --name floating1` 을 붙여 바꾸며 설치

- 👤 sudo 비밀번호 1회 · 시간대 질문 1회(Enter = 지금 값) · 모터 랜카드가 둘 이상이면 고르기
- 나머지는 저절로 · 자동 업데이트·절전·화면 잠금 끄기 · 자동 로그인 · 로그아웃해도 유지 · 방화벽 같은 망 허용 ·
  EtherLab 설치 · 모터 랜카드 설정 · 코드 받기(`~/ros2_ws`) · 빌드 · 서비스 등록
- 중간에 **스스로 재부팅 1회** → 자동 로그인 → 저절로 이어서 끝 (몇 분) · 끝에 자가 점검표
- 점검표에 `[확인]` 이 있으면 그 줄만 본다 · 실시간 권한은 재부팅 뒤 적용

### 2-3. 👤 웹 화면에서 (이 PC 브라우저 `http://localhost:8000` · 또는 다른 PC 에서 `http://<IP>:8000`)

| 순서 | 위치 | 할 일 |
|---|---|---|
| 1 | `설정` → `프로젝트 관리` | 새 프로젝트 · 선택 |
| 2 | `시스템 정보` → 로봇 팩 | 로봇 팩 zip 업로드 (MuJoCo 3D 에 필요) |
| 3 | `설정` → `모터 관리` → `1. 장비 검색` | 모터 드라이브 전원 ON · `전체 모터 검색` |
| 4 | 같은 화면 | `앱솔루트 설정 (전체)` · 👤 안내에 따라 **드라이브 전원 끄고 켜기 2번** · 끝나면 화면 맨 위 빨간 「앱솔루트」 경고가 사라짐 |
| 5 | `3. 조인트 매핑` | 조인트 ↔ 모터 · 기준점 · **최소·최대(= 소프트 리밋)** |
| 6 | 맨 아래 바 | 저장 → 장비에 적용 · 모터 재시작 |
| 7 | `실행` → `애니메이션 재생` | 이 로봇의 JSON 올리기 · 재생 등록 · 웹 3D 로 미리 보기 |
| 8 | `실행` → `PC 연동 설정` | 연동 사용 · 그룹 ID · Domain ID · 역할(마스터는 한 대만) · `설정 저장·연동 재시작` |

**Wi-Fi** · `시스템 정보` → `Wi-Fi` 에서 바꿀 수 있음 · 바꾸면 60초 안에 「유지」(안 누르면 이전 연결로) · 2026-10-08 전에 설치한 PC 는 터미널에서 한 번 `bash ~/ros2_ws/scripts/allow_web_admin.sh`(관리자 비밀번호)

**확인** · `bash ~/ros2_ws/scripts/check.sh` → 6 · 화면 맨 위 PC 이름이 floating1 · 애니메이션을 한 번 재생해 본다(처음은 느리게).

## 3. 스피커 PC · 한 대

### 3-1. 👤 연결

- 공유기(Wi-Fi 또는 유선)
- **스피커를 먼저 꽂는다** · 설치가 꽂힌 사운드 카드를 보고 출력 장치를 자동으로 고른다(HDMI 아닌 첫 카드)

### 3-2. 한 줄 설치

```bash
curl -fsSL https://raw.githubusercontent.com/y0ung-GMLAB/robot_web/main/scripts/bootstrap.sh | bash -s -- --speaker
```

- 「같은 망 PC」 표에 보이는 이름은 컴퓨터 이름 · 바꾸려면 `--speaker --name speaker`

- 👤 sudo 비밀번호 1회 · 나머지 저절로 · 코드는 `~/robot_web` · 모터·로봇 웹은 깔지 않는다
- 끝에 스피커 화면 주소가 찍힌다 · 👤 `재부팅 1회 필요` 가 찍히면 `sudo reboot`
- 옛 `~/speaker_app` 이 있으면 음원과 설정을 옮겨 온다

### 3-3. 👤 스피커 화면에서 (`http://<스피커 IP>:8100`)

| 순서 | 위치 | 할 일 |
|---|---|---|
| 1 | 연동 설정 | 그룹 ID 를 로봇 PC 와 같게 · `적용` |
| 2 | 음성 파일 | wav 올리기(여러 개 가능) · 기본 음원 고르기 · `기본 음원 테스트 재생` 으로 소리 확인 · 볼륨 |
| 3 | 애니메이션별 음원 | 애니메이션마다 음원 고르기 · 로봇이 한 번 재생하면 이름이 저절로 생긴다 |

**확인** · `bash ~/robot_web/scripts/check.sh` → 6 · 맨 위 배지 `DDS 연결됨` · 로봇이 재생하면 로그에 `start_at 수신 (… 애니메이션 이름 · 음원)`.

## 5. 코드 갱신 (전시 전·중)

**5대를 같은 커밋으로 함께** 올린다 · PC 끼리 주고받는 메시지 형식이 바뀌면 섞인 채로는 서로 못 알아듣는다
(마스터 「같은 망 PC」 표에서 버전이 다른 PC 가 빨갛게 보인다).

| PC | 명령 |
|---|---|
| 로봇 PC | `bash ~/ros2_ws/scripts/install.sh` (또는 2-2 의 한 줄을 다시) |
| 스피커 PC | `bash ~/robot_web/scripts/install_speaker.sh` |

## 6. 설치 확인 · PC 마다 한 줄

바꾸는 것 없이 읽기만 한다 · 몇 번 쳐도 된다 · 로봇 PC 인지 스피커 PC 인지 스스로 가린다.

| PC | 명령 |
|---|---|
| 로봇 PC | `bash ~/ros2_ws/scripts/check.sh` |
| 스피커 PC | `bash ~/robot_web/scripts/check.sh` |

`[OK]` · `[확인]` · `[정보]` 로 한 줄씩 찍고 끝에 `결과 · 모두 OK` 또는 `[확인] N개` · `[확인]` 줄 끝의 안내대로 하고 다시 친다.

| 보는 것 | 로봇 PC | 스피커 PC |
|---|---|---|
| 공통 | 공유기 IP · 코드가 최신 main · linger · 자동 업데이트 꺼짐 · 시간대 | 같음 |
| 설치 | 자동 로그인 · 실시간 권한 · Secure Boot 꺼짐 · 서비스 3개 · EtherCAT · 드라이브 수 | speaker-app · 그룹 메시지 빌드 |
| 화면 | 웹 `:8000` · 앱솔루트 경고 없음 | 스피커 화면 `:8100` |
| 연동 | 이 PC ID = 컴퓨터 이름 · 연동 사용 · 그룹 · Domain · 그룹 참가 · **같은 망 PC 목록(끊김 · 버전 다름 표시)** | 연동 모드 · DDS 시작 · 로봇 PC 신호 · 그룹 · 이름 |
| 소리 | | 음원 수 · 기본 음원 · 출력 장치가 실제로 있음 |

- `motion-motor` 는 모터 설정을 「장비에 적용」 하기 전이면 꺼져 있는 게 정상이다(모터가 멋대로 돌지 않게)
- **전체 확인은 마스터에서** · 마스터의 `같은 망 PC` 줄에 나머지 4대(로봇 3 + 스피커 1)가 모두 `[OK]` 면 5대 연결 · 버전이 같다
- 스크립트가 못 보는 것(👤) · BIOS 전원 복구(전원 뽑았다 꽂기) · 실제 소리 · 모터 움직임(튐 · 처짐)

## 8. 안 될 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 「같은 망 PC」 에 안 보임 | 같은 공유기 · 같은 Domain ID · 그 PC 도 최신 코드 · 그 PC 의 연동 서비스(로봇) / 스피커 앱 |
| 모터가 안 잡힘 · `ethercat slaves` 비어 있음 | Secure Boot · 모터 랜선 포트 · 드라이브 전원 · 자가 점검표 EtherCAT 줄 |
| 모든 모터 동작이 막힘 · 빨간 「앱솔루트」 경고 | 2-3 의 4번 앱솔루트 설정 |
| 스피커 소리 없음 | 스피커 화면 출력 장치 · 테스트 재생 · `bash ~/robot_web/speaker_app/deploy/setup-audio.sh` |
| 스피커가 신호를 못 받음 | 그룹 ID · Domain ID · 로봇 PC 와 같은 커밋 |
| 전원 넣어도 안 켜짐 | 1 BIOS |
| 그 밖 | `check.sh` 의 `[확인]` 줄 · README 「안 될 때 먼저 볼 곳」 |
