## 1. 시작하기

**이 문서를 웹에서 보기** : `운영` → `사용법` · 설치법도 같은 자리에 있습니다

**주소** : `http://localhost:8000`
**다른 PC 에서** : `http://<그 PC 주소>:8000` · 예 `http://172.16.21.10:8000`

### 화면 구성

**묶음** : 3개 · 그 아래에 탭

| 묶음 | 탭 |
|---|---|
| 운영 | 실시간 모니터링 · 재생 기록 · 서보 에러 관리 · 로그 · 사용법 |
| 실행 | 애니메이션 재생 · 수동 조작 · PC 연동 설정 |
| 설정 | 모터 관리 · 프로젝트 관리 · 시스템 정보 |

**맨 위 오른쪽** : 운전 모드 세그먼트(`스케줄 | 수동 | 오프`) ·
`📅 재생 스케줄` 버튼 · 스케줄러 상태 딱지 · `전체 동작 정지` · `긴급 정지`

📷 *(캡처: 화면 맨 위 · 묶음 3개와 모드 세그먼트)*

### 말 두 개만 알면 됩니다

| 말 | 뜻 |
|---|---|
| **모터** | 실제 장비 · 번호(0, 1, 2 …)로 부름 |
| **조인트 이름** | 움직임의 이름 · **Blender 본 이름 그대로** · 예 `Neck_Yaw` |

조인트 이름과 모터를 맺는 것이 **조인트 매핑**입니다 · [4장](#4-모터-관리).
애니메이션 파일은 조인트 이름으로 값을 담고, 재생할 때 연결을 따라
모터로 갑니다 · 연결에 없는 조인트 이름은 조용히 무시됩니다 (한 파일을 여러
PC 에 넣어도 각자 제 조인트 이름만 돌립니다).

### 딱지 색

| 색 | 뜻 |
|---|---|
| 🟢 초록 | 정상 · 시각이 되면 돎 |
| 🟡 노랑 | 돌아야 하는데 못 돎 |
| 🔴 빨강 | 계속 못 돎 |
| ⚫ 회색 | 스케줄이 손대지 않음 (수동·오프) |

**이유 보기** : 딱지에 마우스 올리기

### 화면 맨 위 버튼

| 버튼 | 무엇 |
|---|---|
| `전체 동작 정지` | 모든 모터 즉시 정지 · 서보는 켜진 채 |
| `긴급 정지` | 전체 정지 + AC 서보 끔 + 명령 잠금 · 프로그램 재시작 전까지 안 풀림 |
| `프로그램 재시작` | 프로그램 전체 재시작 · 확인 창 뜸 |

**위치** : 어느 화면에서든 늘 보임
**주의** : 스케줄 모드에서 정지하면 최대 1분 뒤 다시 시작 → 계속 멈추려면
[2장](#2-운전-모드)의 수동(또는 오프)으로 먼저

## 2. 운전 모드

**위치** : 화면 맨 위 세그먼트 `스케줄 | 수동 | 오프` · 어느 화면에서든 한 번에

| 모드 | 스케줄 | 사람 조작 (재생·조그·페이더) | 쓰임 |
|---|---|---|---|
| **스케줄** | 돌림 | 됨 | 평소 전시 |
| **수동** | 멈춤 | 됨 | 정비 · 시험 · 애니메이션 교체 |
| **오프** | 멈춤 | **전부 차단** | 사람이 장비에 붙어 일할 때 |

**오프가 막는 것** : 조그 · 페이더 · 재생 시작 · 초기 위치 이동 · 그룹 시작
**오프가 안 막는 것** : 정지 · 긴급 정지 · 서보 켜고 끄기 · 알람 해제 · 조회
**오프에서 서보** : 켠 채 그 자리를 **버티고** 있습니다 · 힘을 빼려면 서보 끄기를 따로

**위험한 방향은 묻습니다** : 스케줄로 갈 때(운영시간이면 곧바로 재생될 수
있음) · 오프로 갈 때 · 수동으로는 바로 갑니다

**여러 대를 묶었을 때** : 모드는 마스터에서만 바꿀 수 있고 슬레이브는 잠김

## 4. 모터 관리

**위치** : `설정` → `모터 관리` · 한 화면에서 1→4 차례로
**하는 일** : 모터를 찾아 등록하고 · 모터별 운전 한계를 정하고 · 조인트 이름을 맺기

### 순서

```
1) 1. 장비 검색              →  전체 모터 검색
2) 2. 검색 결과 확인 및 모터 편집  →  이름·운전 한계
3) 3. 저장하고 설정 적용       →  설정 저장  →  장비에 적용 · 모터 재시작
4) 4. 조인트 매핑             →  조인트 이름 ↔ 모터 · 감속비 · 기준점
```

### 4-1. 찾기

**위치** : `1. 장비 검색`

| 버튼 | 언제 |
|---|---|
| `전체 모터 검색` | 보통 이것 |
| `AC Servo 검색` | AC 서보만 |
| `Dynamixel 검색` | 다이나믹셀만 |

📷 *(캡처: 검색 결과가 나온 표)*

**안 나올 때** : [12장](#12-문제가-생겼을-때)

### 4-2. 모터 편집

**위치** : `2. 검색 결과 확인 및 모터 편집`
**방법** : 표에서 줄을 누르고 아래 버튼 · 이름과 **운전 속도 · 드라이브 설정**은 표에서 바로 고침

**운전 속도 (모터 deg/s)** : 모터마다 따로 · 빈 칸이면 드라이버 기본값 ·
흐린 숫자 = 실행 중인 모터 설정 파일의 값

**하한·상한은 여기서 안 고칩니다** : 원본은 [4-4 조인트 매핑](#4-4-조인트-매핑)의
최소·최대 하나 · 매핑을 저장하면 모터 deg 로 환산돼 모터 설정에 들어갑니다 ·
`상세 설정 표`에는 읽기 전용으로 보입니다

**드라이브 설정 (MINAS)** :

| 칸 | 무엇 | 값 |
|---|---|---|
| 브레이크·정지 (ms) | 멈춘 채 서보 OFF → 브레이크가 잡힐 때까지 전류 유지 | 0~10000 |
| 브레이크·동작 (ms) | 도는 중 서보 OFF → 브레이크 신호까지 | 0~10000 |
| 앱솔루트 | 엔코더 방식 · **드라이브 전원을 껐다 켜야 반영** | 인크리멘털 / 절대 / 절대·다회전 무시 |
| 리밋 스위치 | 구동 금지 입력 · **배선 안 된 축에 켜면 못 움직이거나 Err38** | 사용·그 방향 금지 / 사용 안 함 / 사용·알람 |
| 과부하율 읽기 | 모니터링에 과부하율 표시 · 드라이브 Ver1.03 이상만 | 끔 / 켬 |

- 빈 칸 · 첫 항목 「유지」 = 드라이브에 있는 값을 그대로 둠
- 흐린 글씨 = **마지막 `전체 모터 검색` 때 드라이브에서 읽은 값** · 검색 전이면 「검색 후 표시」 · 못 읽으면 「읽기 실패」

| 버튼 | 무엇 |
|---|---|
| `선택 모터 추가` | 이 프로젝트에서 쓰겠다고 등록 |
| `모델·운전 프로필 설정` | 모터 종류·운전값 지정 |
| `선택 모터 사용상태 변경` | 잠시 안 쓰게 |
| `모터 번호 정렬` | 번호를 차례로 |
| `선택 모터 삭제` | 등록 취소 |
| `선택 모터 검색값 반영` | 검색된 모델·일련번호·연결정보를 덮어쓰기 |
| `EEPROM Alias 변경` | 드라이브에 고유 번호 적기 · 랜선 순서가 바뀌어도 같은 모터로 인식 |

**상세 설정 표 탭** : 원본 값(speed · 가감속 · 프로필 등)을 직접 고치는 곳 ·
**모터 목록과 상세 표를 같이 고친 채로는 저장되지 않습니다** · 한쪽을
저장한 뒤 다른 쪽을 고치세요

### 4-3. 저장하고 장비에 넣기

**위치** : `3. 저장하고 설정 적용` · 왼쪽부터

| | 버튼 | 무엇이 되나 |
|---|---|---|
| 1단계 | `설정 저장` | 설정 파일에 적힘 · 모터는 그대로 |
| 2단계 | `장비에 적용 · 모터 재시작` | 실제 모터에 들어감 · 모터가 잠깐 멈췄다 켜짐 |

**주의** : 2단계를 안 누르면 모터는 안 바뀜 · 파일만 바뀜

### 4-4. 조인트 매핑

**위치** : `4. 조인트 매핑`
**하는 일** : 조인트 이름(= Blender 본 이름)를 모터에 맺고 변환값을 정함
**언제** : 애니메이션을 올리기 **전에** · 연결이 없으면 애니메이션을 받지 않습니다

```
1) 조인트 매핑 편집   →  자동 생성
2) 줄마다 조인트 이름을 Blender 본 이름으로  (예 Neck_Yaw · Eye_Pitch)
3) 감속비·반전·최소·최대 입력
4) 기준점 캡처   →  지금 모터 위치가 그 조인트 이름의 0° 가 됨
5) 검증·미리보기·저장
```

| 칸 | 무엇 |
|---|---|
| 조인트 이름 | Blender 본 이름 그대로 · 옛 `1-1` 식 이름도 그대로 동작 |
| 모터 | 이 조인트 이름이 움직일 모터 번호 |
| 감속비 | 모션 1° = 모터 몇 ° · 예 목 좌우 1:100 이면 `100` |
| 반전 | 방향이 반대면 켬 · Blender 쪽은 고치지 않음 |
| 기준점 | 모션 0° 일 때의 모터 위치 · `기준점 캡처`로 채움 |
| 최소·최대 | 조인트 이름이 움직여도 되는 범위 (deg) · **리밋의 유일한 원본** · 재생 클리핑 · 페이더 범위 · 모터 운전 한계(드라이브 soft limit)가 전부 이것 |

**최소·최대 → 모터 운전 한계** : 저장하면 `기준점 + (값 + offset) × 배율 × 방향 × 감속비` 로
모터 deg 를 계산해 모터 설정에 넣습니다 · 드라이브 반영은 `장비에 적용 · 모터 재시작` 후 ·
수동 조작 다이얼의 `− limit` `+ limit` 도 여기(최소·최대)에 저장됩니다

**기준점 캡처가 눌리려면** : 4-3 의 적용이 끝나 장비가 돌고 있어야 합니다

📷 *(캡처: 4. 조인트 매핑 · 조인트 이름과 모터가 맺어진 표)*

## 5. 애니메이션 올리기

**만드는 곳** : Blender · 리그에서 본 애니메이션을 만들고 export 스크립트로
`.json` 을 뽑습니다 (제작 절차는 리그 쪽 문서)
**파일 내용** : 조인트 이름별 각도(deg) · 50fps(20ms) 한 줄씩

### 올리는 법

```
1) 실행 → 애니메이션 재생
2) 「불러오기」로 .json 고르기 (여러 개 가능)
   또는 .json 파일·폴더를 애니메이션 화면에 끌어다 놓기
```

끝. 폴더를 놓으면 그 안의 `.json` 만 올라갑니다 · `프로젝트 관리` 의
`내 PC에서 가져오기` 로도 올릴 수 있습니다 · 실패하면 사유가 창으로 뜹니다.

**거부되는 경우** :

| 메시지 | 할 일 |
|---|---|
| 조인트 매핑이 없는 프로젝트에는… | [4-4](#4-4-조인트-매핑) 먼저 |
| 같은 이름 파일이 이미 있음 | Blender 쪽 파일 이름을 바꿔 다시 |
| 형식 오류 | export 를 다시 뽑기 · 손으로 고친 파일인지 확인 |

**여러 PC** : 같은 파일을 각 PC 에 올려도 됩니다 · 각 PC 는 자기 조인트
설정에 있는 이름만 돌리고 나머지는 무시합니다

## 6. 수동 조작

**위치** : `실행` → `수동 조작`
**언제** : 설치 확인 · 방향·범위 점검 · 손으로 움직여 보고 싶을 때

### 순서

```
1) 1. 시험할 모터 선택
2) 2. 서보 준비        →  서보 켜기  (오류 있으면 오류 초기화)
3) 페이더 또는 4. 동작 명령
4) 결과 확인
```

### 페이더 (실시간 드래그)

**위치** : 서보 준비 바로 아래 `페이더 · 실시간 드래그`
**무엇** : 조인트마다 슬라이더 하나 · **잡고 끄는 동안만** 모터가 따라오고 ·
**놓으면 그 자리에 섭니다**

- 범위 = 조인트 매핑의 최소·최대 · 그 밖으로는 안 나감
- 잡지 않은 페이더는 실제 모터 위치를 따라 움직임
- 재생이 돌고 있는 조인트 이름은 재생이 우선 · 페이더 명령은 거부됨
- 조인트 매핑을 다른 화면에서 고쳤다면 거부됨 · 화면 새로고침 후 다시
- 오프 모드에서는 동작하지 않음

📷 *(캡처: 수동 조작 · 페이더 줄)*

### 조그 (버튼으로 조금씩)

**위치** : `4. 동작 명령` → 조그 모드

| 항목 | 무엇 |
|---|---|
| 조그 이동량 (도) | 한 번 누를 때 움직일 각도 |
| **조그 단위** | **조인트 deg 기준** 이 기본 · 감속비와 방향이 적용됨 · 끄면 모터 deg 그대로 |
| `- 방향` `+ 방향` | 그 방향으로 한 번 |

**조인트 deg 기준이면** : 목 좌우(1:100)에서 `1` 을 치면 조인트 이름이 1° (모터는 100°) 돕니다 ·
끄면 모터축이 1° 돌아 조인트 이름은 거의 안 움직입니다

### 다이얼 · 목표 위치 이동 (모터 deg)

**위치** : `4. 동작 명령` → 조그 모드 아래 다이얼

| 항목 | 무엇 |
|---|---|
| `다이얼` ON | 돌린 만큼 모터가 움직임 · 한 칸 = 입력한 모터 deg |
| `다이얼` OFF | `목표 위치 (모터 deg)` 입력 → `이동` (또는 Enter) · 속도·가속은 모터 설정 한계를 따름 |
| 모터 위치 | 다이얼·목표 칸 공통 · 목표 칸은 처음에 지금 위치로 채워짐 |
| `동작 취소` | 남은 다이얼 이동을 버리고 움직이는 조그·이동을 멈춤 · 서보 ON 유지 · 늘 누를 수 있음 |

- 옛 「동작 모드」(출력축 도 · 감속비 손입력)는 없앴습니다

**슬레이브** : 스케줄이 아무 일도 안 함 · 마스터가 보내는 그룹 실행만 따름
**설정하는 곳** : 마스터에서만 · 슬레이브는 화면이 잠김

```
4) PC 연동 표에서 모든 PC 가 🟢 정상인지 확인   (여러 대 쓸 때)
```

**시작 시각이 되면 알아서 돕니다.** 손댈 것 없습니다.

### 저녁에 닫을 때

**할 것 없음.** 종료 시각이 되면 현재 회차를 끝내고 멈춥니다.
**PC 전원** : 꺼도 되고 켜 둬도 됨 · 다음 날 알아서 다시 돎

### 잠깐 멈출 때 (관람객 접근 · 점검)

```
1) 맨 위 세그먼트  →  「수동」      ← 먼저!
2) 전체 동작 정지
```

**순서가 중요합니다.** 정지를 먼저 누르면 1분 안에 다시 시작합니다.
**다시 돌리기** : 세그먼트 → `스케줄` · 1분 안에 시작

### 장비에 붙어 일할 때

```
1) 맨 위 세그먼트  →  「오프」
2) 작업
3) 끝나면  →  「스케줄」(또는 「수동」)
```

오프 동안은 어느 화면의 어떤 버튼도 모터를 못 움직입니다 ·
서보는 켠 채 자리를 지킵니다.

### 당장 세워야 할 때

**버튼** : 화면 맨 위 `전체 동작 정지` · 더 급하면 `긴급 정지`
**주의** : 스케줄 모드면 1분 뒤 다시 시작 → 계속 세우려면 수동·오프로

### 애니메이션을 바꿀 때

```
1) 맨 위 세그먼트  →  「수동」
2) Blender 에서 고치고 .json 다시 export
3) 실행 → 애니메이션 재생   →  파일 끌어다 놓기  →  「재생 등록」
4) 1회 시작 으로 확인
5) 세그먼트  →  「스케줄」
```

**여러 대 쓸 때** : 각 PC 가 자기 애니메이션을 돌므로 **바꿀 PC 에서만** 하면 됨

### 모터 설정을 바꿀 때

```
1) 맨 위 세그먼트  →  「수동」
2) 전체 동작 정지
3) 설정 → 모터 관리   →  값 수정
4) 설정 저장  →  장비에 적용 · 모터 재시작
5) 실행 → 수동 조작      →  모터 하나씩 확인
6) 세그먼트  →  「스케줄」
```

**주의** : 4단계의 두 번째 버튼을 안 누르면 모터는 안 바뀜

### 한 대만 정비할 때 (여러 대 쓸 때)

```
1) 그 PC 화면에서  PC 연동 → 「지금 빠지기」
2) 정비
3) PC 연동 → 「다시 참가」
```

**나머지 PC** : 계속 돕니다 · 멈출 필요 없음

### 프로그램을 갱신할 때

```
1) 맨 위 세그먼트  →  「수동」   (마스터에서)
2) 모든 PC 에서 (SSH 또는 그 PC 의 터미널)  bash scripts/install.sh
3) 끝나면 PC 연동 표에서 버전이 모두 같은지 확인
4) 오류가 있으면  「그룹 오류 확인」  한 번
5) 세그먼트  →  「스케줄」
```

**주의** : **모든 PC** 를 갱신해야 함 · 한 대만 하면 버전이 갈림 ·
특히 오프 모드는 구버전이 모르는 값이라 **반드시 전 PC 를 같이** 올릴 것

### 정전이 났다 복구됐을 때

**할 것 없음.**

```
전원 복구  →  PC 자동 켜짐  →  프로그램 자동 시작  →  구간 안이면 1분 안에 재생 시작
```

**확인만** : 딱지가 🟢 인지 · PC 연동 표가 모두 🟢 인지

### 다른 나라·도시로 옮겼을 때

```
1) 터미널에서  timedatectl                          (시간대 확인)
2) sudo timedatectl set-timezone <지역/도시>
3) bash scripts/install.sh                   (프로그램 다시 올리기)
4) 📅 재생 스케줄 위쪽  🕒 PC 시각  이 현지 시각인지 확인
```

**안 하면** : 스케줄이 옛 나라 시각으로 돎
**스케줄 시각** : 고칠 필요 없음 · 현지 시각으로 해석됨

### 긴급 정지를 눌렀을 때

```
1) 원인 해결
2) 프로그램 재시작        (화면 맨 위 또는 시스템 정보)
3) 딱지가 🟢 인지 확인
```

**주의** : 긴급 정지는 **재시작 전까지 안 풀립니다**

## 12. 문제가 생겼을 때

### 자주 나오는 것

| 증상 | 원인 | 할 일 |
|---|---|---|
| 검색해도 모터가 안 나옴 | 전원·랜선 | 서보 전원과 EtherCAT 랜선 확인 |
| 설정을 바꿨는데 모터가 그대로 | 2단계 안 누름 | `장비에 적용 · 모터 재시작` |
| 애니메이션을 끌어다 놔도 안 들어감 | 조인트 매핑 없음 | [4-4](#4-4-조인트-매핑) 먼저 |
| 재생해도 어떤 조인트 이름이 안 움직임 | 이름이 연결에 없음 | 조인트 이름 = Blender 본 이름인지 확인 |
| 조그·페이더가 안 먹음 | 오프 모드 · 서보 꺼짐 | 모드 확인 · `서보 켜기` · `오류 초기화` |
| 조그 1° 에 거의 안 움직임 | 조그 단위가 모터 deg | 조그 단위를 「조인트 deg 기준」으로 |
| 시각이 됐는데 안 돎 | 수동·오프 모드 | 세그먼트를 「스케줄」로 |
| 딱지가 빨강 | 시작이 거부됨 | 딱지에 마우스 올려 이유 확인 |
| 스케줄이 엉뚱한 시각에 돎 | 시간대 다름 | `🕒 PC 시각` 확인 · [README](../README.md) |

### 연동 문제

| 증상 | 할 일 |
|---|---|
| 상대 PC 가 「통신 단절」 | 그 PC 전원 · 그룹 ID·Domain ID 확인 |
| 빨간 오류 창 | `PC 연동` → `그룹 오류 확인` · 아무 PC 한 대에서만 |
| 버전이 서로 다름 | 뒤처진 PC 에서 `bash scripts/install.sh` |
| 서보 알람 | 알람이 난 그 PC 에서 해제 |

### 멈춘 뒤 다시 돌리기

| 어떻게 멈췄나 | 저절로 돌아오나 | 할 일 |
|---|---|---|
| `즉시 정지` · `현재 회차 후 정지` | 예 · 스케줄 모드면 1분 안에 | 그냥 두기 |
| 수동·오프로 바꿈 | 아니오 | 세그먼트를 「스케줄」로 |
| 그룹 오류 | 아니오 | `그룹 오류 확인` |
| 긴급 정지 | 아니오 | 프로그램 전체 재시작 |
