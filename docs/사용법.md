## 1. 시작하기

**이 문서를 웹에서 보기** : `기록·도구` → `사용법` · 위쪽 `설치법` 탭에 설치 문서 · 왼쪽 `문서 검색` 칸 · 업데이트 뒤에는 `새로 고침`

**주소** : `http://localhost:8000/v2`
**다른 PC 에서** : `http://<그 PC 주소>:8000/v2` · 예 `http://172.16.21.10:8000/v2`

### 화면 구성

**위 막대** (어느 화면에서든 늘 보임)

| 자리 | 무엇 |
|---|---|
| 왼쪽 | 접속한 PC 이름 · 역할(`마스터` · `슬레이브` · `단독`) · 그룹 이름 |
| 가운데 | 지금 상태 한 줄 · 누르면 「확인할 일」 창 ([아래](#상태-한-줄과-확인할-일)) |
| 오른쪽 | 운전 모드 `스케줄 · 수동 · 끔` ([2장](#2-운전-모드)) · `정지` · `긴급 정지` |

**왼쪽 메뉴** (좁은 화면에서는 위 막대 왼쪽 `≡` 로 펼침)

| 묶음 | 메뉴 |
|---|---|
| 운영 | 홈 · 재생 · 스케줄 · PC 현황 |
| 작업 | 애니메이션 · 수동 조작 |
| 설정 | 모터 설정 · 로봇 팩·3D · 드라이브 알람 · 네트워크·시간·그룹 · 업데이트·백업 |
| 기록·도구 | 기록 · 터미널 · PC 성능 · 사용법 |
| 맨 아래 | `이전 UI ↗` · 예전 화면(`:8000/`) |

📷 *(캡처: 새 화면 · 위 막대와 왼쪽 메뉴)*

### 말 두 개만 알면 됩니다

| 말 | 뜻 |
|---|---|
| **모터** | 실제 장비 · 번호(0, 1, 2 …)로 부름 |
| **조인트 이름** | 움직임의 이름 · **Blender 본 이름 그대로** · 예 `Neck_Yaw` |

조인트 이름과 모터를 맺는 것이 **조인트 매핑**입니다 · [4-4](#4-4-조인트-매핑).
애니메이션 파일은 조인트 이름으로 값을 담고, 재생할 때 연결을 따라
모터로 갑니다 · 연결에 없는 조인트 이름은 조용히 무시됩니다 (한 파일을 여러
PC 에 넣어도 각자 제 조인트 이름만 돌립니다).

### 상태 한 줄과 확인할 일

**위치** : 위 막대 가운데 · 홈 화면에도 같은 목록

| 색 | 보이는 글 | 뜻 |
|---|---|---|
| 🟢 초록 | `정상 · 스케줄 운영 중` · `정상 · 운영 시간 외` | 문제 없음 · 스케줄 모드 |
| 🔵 파랑 | `수동 · 스케줄 동작 안 함` | 수동 모드 · 스케줄이 손대지 않음 |
| 🟡 노랑 | `… · 확인할 일 N개` | 볼 것이 있음 · 당장 멈춘 것은 아님 |
| 🔴 빨강 | 가장 급한 문제 이름 · 예 `긴급 정지 상태입니다` | 지금 막혀 있음 |

**확인할 일 창** : 상태 줄을 누르면 열림 · 문제마다 이유와 **해결 버튼**
(`프로그램 다시 시작` · `오류 초기화` · `모든 PC 업데이트` · `그룹 오류 해제` · `모터 설정 열기` · `조인트 매핑 열기` · `스케줄 수정`) ·
닫기는 `닫기 ✕` · `Esc` · 창 바깥 누르기 · 해결 버튼 누르기 · 다른 화면으로 가기 · 문제가 없으면 눌리지 않음

**주로 나오는 것** : 긴급 정지 · 모터 제어 응답 없음 · 앱솔루트 미확인 · 조인트 범위 미확인 · 모터 알람 · 재생 오류 · 그룹 오류 ·
스케줄 시작 거부 · 시각을 읽을 수 없는 스케줄 · 버전이 다른 PC · 연결 안 된 PC

### 화면 맨 위 버튼

| 버튼 | 무엇 |
|---|---|
| `정지` | 모든 움직임 정지 · 서보 토크는 유지 · 확인 창 없이 바로 · 「정지했습니다. 서보 토크 유지.」 |
| `긴급 정지` | 서보 끔 + 명령 잠금 · 확인 창 없이 바로 · **프로그램을 다시 시작해야 풀림** |

**프로그램 다시 시작** : 위 막대에는 없습니다 · `네트워크·시간·그룹` → `PC 정보` 의 `프로그램 다시 시작` ·
`업데이트·백업` 맨 아래 · 긴급 정지 뒤에는 「확인할 일」 창에도 버튼이 뜸 · 확인 창 뒤 30초쯤 화면이 끊겼다 다시 붙음
**주의** : 스케줄 모드에서 정지하면 최대 1분 뒤 다시 시작 → 계속 정지해 두려면
[2장](#2-운전-모드)의 `수동`(또는 `끔`)으로 먼저

## 2. 운전 모드

**위치** : 화면 맨 위 `스케줄 · 수동 · 끔` · 어느 화면에서든 한 번에 · 버튼에 마우스를 올리면 뜻이 보임
**뜻** : **누가 시작하나** · `스케줄` = 시간에 맞춰 저절로 · `수동` = 사람이 (단독 · 그룹 둘 다) · `끔` = 움직이지 않음

| 모드 | 스케줄 | 재생 화면 시작 | 수동 조작 (페이더·다이얼) | 그룹 재생에 들어가나 | 쓰임 |
|---|---|---|---|---|---|
| **스케줄** | 돌림 | 막힘 (스케줄이 관리) | 막힘 | 스케줄이 켠 것 · 사람이 누른 것 둘 다 | 평소 전시 |
| **수동** | 안 돎 | 됨 (단독 · 그룹) | 됨 | **사람이 누른 것만** · 스케줄이 켠 것은 빠짐 · 그 PC 에서 조그·페이더·단독 재생 중이면 빠짐 | 정비 · 시험 · 애니메이션 교체 |
| **끔** | 안 돎 | **막힘** | **막힘** | 안 들어감 | 사람이 장비에 붙어 일할 때 |

**스케줄 모드에서 시작 버튼이 막힌 이유** : 사람이 시작·정지해도 스케줄이 곧 다시 시작하기 때문 · 직접 돌리려면 `수동` 으로
**끔이 막는 것** : 다이얼 · 페이더 · 목표 위치 이동 · 재생 시작 · 초기 위치 이동 · 그룹 시작
**끔이 안 막는 것** : 정지 · 긴급 정지 · 서보 켜고 끄기 · 오류 초기화 · 보기
**끔에서 서보** : 켠 채 그 자리를 **버티고** 있습니다 · 힘을 빼려면 서보 끄기를 따로 · 진행 중인 재생은 이번 회차가 끝나면 정지

**확인 창이 뜨는 쪽** : `스케줄` 로 갈 때(운영 시간이면 곧바로 재생될 수 있음) · `끔` 으로 갈 때 → `전환` · `수동` 으로는 바로 갑니다

**여러 대를 묶었을 때** : 모드는 마스터에서만 바꿀 수 있고 슬레이브는 버튼이 잠김 (마우스를 올리면 이유)

## 3. 프로젝트와 백업

**위치** : `설정` → `업데이트·백업` → `프로젝트` 칸 · `백업` 칸
**무엇** : 모터 설정 · 조인트 매핑 · 애니메이션 · 스케줄을 담는 통
**개수** : 로봇 한 대에 하나

### 프로젝트 만들고 고르기

```
1) 프로젝트 칸 「새로 만들기」  →  이름 입력  →  「만들기」
2) 「다른 프로젝트」 목록에서 그 줄의 「선택」  →  확인 창 「전환」
3) 모터 설정 → 「저장 후 장비에 적용」      (고르기만 해서는 장비에 안 들어감)
```

📷 *(캡처: 업데이트·백업 · 프로젝트 칸)*

| 보이는 것 · 버튼 | 무엇 |
|---|---|
| 프로젝트 이름 옆 `장비에 적용됨` · `장비에 미적용` | 지금 모터가 이 프로젝트 설정으로 도는지 |
| `메모` · `메모 저장` | 다음 작업자에게 남길 현장 메모 |
| `선택` | 그 프로젝트로 전환 · 화면의 매핑·애니메이션·스케줄이 바뀜 · 장비 적용은 따로 |
| `삭제` | 프로젝트 이름을 똑같이 입력해야 삭제됨 · 휴지통에 7일 |

### 백업 (zip)

| 버튼 | 무엇 |
|---|---|
| `zip 다운로드` | 지금 프로젝트를 zip 하나로 이 브라우저에 저장 (매핑 · 모터 설정 · 애니메이션 · 스케줄) · **원격으로도 됨 · 설치 후 한 번은 받아 두세요** |
| `zip 파일로 복원` | 받아 둔 zip 으로 프로젝트 복원 · 같은 이름이 있으면 `덮어쓰기` 를 한 번 더 물음 (있던 것은 휴지통) · 복원 뒤 목록에서 `선택` → 모터 설정 `저장 후 장비에 적용` |
| `자동 백업` | 프로그램이 켜져 있으면 하루 한 번 프로젝트마다 zip 을 그 PC 디스크에 저절로 남김 · 14일 보관 · 날짜 줄의 `↓ 프로젝트` 를 누르면 다운로드 → `zip 파일로 복원` · 같은 디스크라 디스크 고장 대비는 `zip 다운로드` 로 |
| `휴지통` | 지운 프로젝트 · 7일 뒤 자동 삭제 · `복원` |

**애니메이션만 받은 경우** : 프로젝트가 아니라 [5장](#5-애니메이션-업로드)처럼 애니메이션 화면에서 업로드합니다

## 4. 모터 설정

**위치** : `설정` → `모터 설정` · **한 페이지에 두 구획** · ① 모터·드라이브 → ② 조인트 매핑 · 맨 아래 저장 칸 하나
**하는 일** : 모터를 찾아 이름과 운전값을 정하고 · 조인트 이름을 모터에 맺고 · 장비에 넣기
**머리** : `① 모터·드라이브` `② 조인트 매핑` 바로 가기 · 오른쪽 상태 `장비에 적용됨` · `장비에 적용됨 · 저장하지 않은 변경 있음` · `장비에 적용 필요`

### 설정 순서

```
1) ① 머리 「전체 검색」               →  모터 찾기 · 결과는 저장 전까지 화면에만
2) ① 모터 표에서 줄 누르기            →  아래 설정 칸 · 이름 · 속도 · 브레이크
3) ① 앱솔루트 줄                     →  모두 정상인지 · 아니면 「앱솔루트 설정 (전체)」
4) ② 「인식 모터 자동 생성」          →  조인트 이름 · 감속·기어비 · 범위 · 기준점
5) 맨 아래 「저장 후 장비에 적용」    →  모터 프로그램이 다시 시작되며 장비에 들어감
```

### 4-0. 다이나믹셀 사전 세팅 (Dynamixel Wizard · 1회)

AC 서보(MINAS)는 이 프로그램이 부팅 때 운전 값(동작 모드 · 속도 · 가감속 · 한계 · 브레이크)을 드라이브에 씁니다 ·
다이나믹셀은 **부팅 때 쓰는 값이 둘뿐**(Torque Enable 0 · Operating Mode 4)이라 나머지는 Dynamixel Wizard 로 미리 넣어야 합니다

| 항목 | 값 | 비고 |
|---|---|---|
| ID | 같은 포트 안에서 고유 · 0~252 | 검색은 이 범위만 봄 |
| Baud Rate | 1,000,000 | 프로그램 고정값 · 다른 값이면 검색 안 됨 |
| Protocol | 2.0 | X 시리즈 기본 |
| Operating Mode | 4 (Extended Position) | 프로그램이 켜질 때 장치 값을 읽어 **다를 때만** 4 로 씀(그때만 토크가 잠깐 꺼짐) · 같으면 그대로 · 평소 재시작에 처짐 없음 |
| Profile Velocity · Profile Acceleration | 원하는 속도·가속 | 장치 저장값 그대로 사용 · **0 이면 무제한 속도** |
| Shutdown · Return Delay Time 등 | 장치 기본값 또는 현장 값 | 프로그램이 쓰지 않음 |

**오류가 났을 때** : 과부하·과열·전압 오류(Hardware Error)는 모터 표 `서보` 칸 `오류` 와 「확인할 일」 의 `모터 알람 · N번 (오류 이름)` 으로 보임 ·
장치가 스스로 토크를 끈다 · 원인 제거 → `재부팅`(모터 설정 설정 칸의 `드라이브 관리` 또는 수동 조작의 서보 칸) → 오류가 풀리고 토크 꺼진 채
다시 켜짐 → 위치 확인 → `토크 켜기` · 재부팅해도 안 풀리면 전원 재투입 · **다회전(모드 4) 모터는 재부팅하면 바퀴 수가

### 4-3. 앱솔루트 (필수)

**앱솔루트가 아니면 모든 모터 동작이 막힙니다**

- 대상 · EtherCAT 에 연결된 **MINAS 드라이브 전부** · 이 프로젝트에 등록 안 한 드라이브도 · 다이나믹셀은 아님
- 언제 읽나 · 프로그램이 뜬 직후 + 드라이브 구성이 바뀔 때(전원 재투입 · 랜선) · Pr0.15(0x3015) · 오류(0x603F) · 읽는 동안 잠깐 막힘
- 모터 프로그램이 드라이브를 설정하는 동안(부팅 · `장비에 적용` · 모터 재시작 직후 · 모든 드라이브가 OP 가 될 때까지 · 보통 10~20 초 · 길어야 90 초)은 읽지 않음 · 그동안 `확인 중` · 이때 읽으면 드라이브 설정이 깨져 PREOP 에 멈췄음(수정 목록 125)
- 막히는 경우 · Pr0.15 ≠ 0 · 읽기 실패 · Err40(다회전 무효)
- 막히는 것 · 서보 켜기 · 토크 켜기 · 다이얼 · 페이더 · 목표 위치 이동 · 초기 위치 이동 · 재생 · 스케줄 · 그룹 참가
- 막히지 않는 것 · 서보 끄기 · 오류 초기화 · 정지 · 긴급 정지 · 모터 검색 · 드라이브 관리 버튼
- 예외 · 모터 프로그램이 뜰 때 스스로 켜는 서보는 막지 않음 · 제자리만 잡고 움직이지 않음 · 브레이크 없는 축이 처지지 않게
- 보이는 곳 · 「확인할 일」 `앱솔루트 방식이 확인되지 않아 모터를 움직일 수 없습니다` + `모터 설정 열기` · ① 구획의 `앱솔루트 N/M 정상` 줄 ·
  모터 표 `앱솔루트` 칸(`정상` · `앱솔루트 아님` · `확인 안 됨` · `다회전 무효(Err40)` · 마우스를 올리면 이유)

**푸는 법** : ① 구획 `앱솔루트 설정 (전체)` 또는 설정 칸의 `앱솔루트 설정` → 확인 창(대상 · 건너뜀 · 순서) → `시작` → 화면 줄 `앱솔루트 설정 중 · n/m · 단계`

1. 서보 끄기(대상 축)
2. Pr0.15 = 0 · EEPROM 저장 (모터 프로그램 잠시 정지)
3. **드라이브 전원 껐다 켜기** · 화면이 「전원 꺼짐 대기 · 다시 켜짐 대기」 로 알려 줌 · 드라이브가 빠졌다 돌아오면 자동으로 다음
4. Pr0.15 되읽기
5. 다회전 클리어
6. **드라이브 전원 한 번 더**
7. 검증(Pr0.15 = 0 · 오류 0 · 위치 한 바퀴 안) → `앱솔루트 설정 완료` · 위치 숫자가 바뀌므로 **기준점을 다시 캡처** (모터가 움직이는 것이 아니라 위치 값이 한 바퀴 안으로 바뀜 · 설치 때 한 번)

- 실패하면 그 단계에서 정지하고 원인을 보여 줌 · 모터 프로그램은 늘 다시 띄움 · 전원 재투입 대기 중에는 `취소` · 30분 넘으면 시간 초과 · 결과는 운영 로그(시스템)
- 진행 중에는 모든 모터 동작 · 모터 검색 · 낱개 드라이브 관리 버튼이 막힘 · 등록 안 한 드라이브도 `전체` 로 처리됨

### 4-4. 조인트 매핑

**위치** : ② 구획 (`#/mapping` 주소나 다른 화면의 `조인트 매핑 열기` 로 오면 여기로 내려옴)
**하는 일** : 조인트 이름(= Blender 본 이름)을 모터에 맺고 변환값을 정함 · `모터 = 기준점 + 조인트 × 감속·기어비 × 방향`
**언제** : 애니메이션을 업로드하기 **전에** · 매핑이 없으면 애니메이션을 받지 않습니다

```
1) 「인식 모터 자동 생성」  →  모터마다 한 줄   (모터를 직접 고르려면 「+ 조인트」)
2) 줄마다 조인트 이름을 Blender 본 이름으로  (예 Neck_Yaw · Eye_Pitch)
3) 감속·기어비 · 방향 반전 · 범위 입력  (범위 = 실제 기계 범위 · 스펙·CAD 값) → 맞는지 확인하고 「범위 확인」 직접 체크
4) 맨 아래 「저장 후 장비에 적용」
   └ 여기까지 와야 다이얼·페이더가 움직임 (범위 미확인이면 수동 조작도 거절)
5) 수동 조작으로 정면·수평에 맞춤  →  기준점 「캡처」   →  지금 모터 위치가 그 조인트의 0° 가 됨
6) 다시 「저장 후 장비에 적용」
```

| 칸 | 무엇 |
|---|---|
| 사용 | 끄면 그 줄은 재생·수동 조작에 안 씀 |
| 조인트 | Blender 본 이름 그대로 · 옛 `1-1` 식 이름도 그대로 동작 · 비거나 겹치면 저장이 막힘 |
| 모터 | 이 조인트가 움직일 모터 · 목록에 `0번 · 이름 (AC · 슬레이브 0 · alias 100)` 처럼 어느 드라이브인지 같이 보임 · 다이나믹셀은 `(DXL · 포트 · ID n)` · 못 찾으면 `(인식 안 됨)` · 한 모터를 두 줄이 쓰면 저장이 막힘 |
| 감속·기어비 | 조인트 1° = 모터 몇 ° · 감속기·외부 기어·벨트 **·링크 비율까지 곱해서** 한 숫자로 · 예 목 좌우 1:100 이면 `100` · 다이나믹셀도 같은 칸 (1 고정 아님) · 예 플로팅 눈 좌우 = 1:35 × 링크 약 1.047 ≈ `36.6` · 눈 상하 = 1:50 × 링크 약 1.786 ≈ `89.3` (링크 때문에 반대로 돌면 `방향 반전`) |
| 방향 반전 | 방향이 반대면 켬 · Blender 쪽은 고치지 않음 |
| 기준점 (모터°) | 조인트 0° 일 때의 모터 위치 · 옆 `캡처` 로 지금 모터 위치를 넣음 · 저장해야 반영 |
| 범위 (조인트°) | 조인트가 움직여도 되는 최소 ~ 최대 (deg) · **리밋의 유일한 원본** · 재생 자르기 · 페이더 범위 · 모터 운전 한계(AC 서보 드라이브 소프트 리밋 · 다이나믹셀은 아래 「다이나믹셀 리밋」)가 전부 이것 |
| 범위 확인 | 범위가 이 로봇의 **실제 기계 범위**인가 · 새로 만든 줄은 꺼짐(−180 ~ 180 은 기계 범위가 아님) · **사람이 직접 체크**(최소·최대를 입력하거나 수동 조작에서 `하한점 지정`·`상한점 지정` 해도 저절로 켜지지 않음 · 칸 옆 `범위 확인 유의 · 실제 기계 범위인지 확인한 뒤 체크`) · 업데이트 전 파일(칸 없음)은 범위가 −180 ~ 180 이 아니면 확인된 것으로 봄 · **「사용」 줄이 하나라도 꺼져 있으면 재생·초기 위치 이동·수동 조작 거절**(그룹에서는 그 PC 만 빠짐 · 「확인할 일」 에 `조인트 범위가 확인되지 않아…`) · 저장 · 서보 켜고 끄기 · 정지 · 오류 초기화 · 기준점 캡처는 됨 |
| 최대 속도 · 가속 | 조인트 deg/s · deg/s² · **비우면 검사 안 함** · 적으면 애니메이션이 넘을 때 재생 시작이 거부되고 어느 조인트가 몇 초에 얼마나 넘는지 알려 줌 (재생과 같은 20 ms 값으로 잼) |
| 초기 위치 | 재생 전에 먼저 옮겨 둘 자세 · `기준점 (0°)` = 늘 조인트 0° · `첫 프레임` = 애니메이션 첫 줄 값 · `지정 값` = 옆 칸의 조인트 deg |
| 상태 | 저장 때 검사 결과 · 마우스를 올리면 전체 글 |
| `삭제` | 그 줄 삭제 (저장해야 반영) |

**캡처가 눌리지 않을 때** : 버튼에 마우스를 올리면 이유가 나옵니다 ·
`모터 설정이 아직 장비에 적용되지 않았습니다` (→ `저장 후 장비에 적용` 먼저 · 모터 설정에 겹치는 주소 같은 문제가 있으면 그 이유) ·
`이 줄에 연결된 모터를 찾지 못했습니다` (→ `모터` 칸) · `이 모터의 현재 위치를 아직 받지 못했습니다`

**미리보기 칸** : 표에서 줄을 누르면 아래에 `조인트 +1° → 모터 N°` · `범위 → 모터 한계` · 검사 오류·경고
**원본 파일** : 맨 아래 `원본 파일 · motion_axis.yaml (저장된 내용)` 을 펼치면 저장된 파일 그대로 · 보기만
**로봇 팩과 비교** : ② 구획 설명 줄의 링크 → [로봇 팩·3D](#로봇-팩3d)

**범위 → 모터 운전 한계** : 저장하면 위 식으로 모터 deg 를 계산해 모터 설정에 넣습니다 · 드라이브 반영은 `저장 후 장비에 적용` 뒤 ·
수동 조작의 `하한점 지정` · `상한점 지정` 도 여기(범위)에 저장됩니다

**다이나믹셀 리밋** : 다이나믹셀은 Extended Position(멀티턴) 모드로 돌아 장치의 Min/Max Position Limit 이
적용되지 않고, 설정 파일(`config/dynamixel_*.yaml`)도 한계를 장치에 쓰지 않습니다 · 한계는 소프트웨어가 지킵니다 ·
① 수동 다이얼·목표 위치 이동·페이더 → 환산한 운전 한계 밖이면 보내지 않음 ② 재생 → 계획 단계에서 범위 안으로 자르고,
보내는 단계에서도 밖이면 경계값으로 보냄(로그 경고) · 한 바퀴(±180°) 제한은 없으며 장치 범위(±256 바퀴) 안에서
여러 바퀴를 돌 수 있습니다 · **감속·기어비가 1 이 아니면 모터가 여러 바퀴 돌 수 있으므로 범위를 반드시 실제
기계 범위로 넣으세요** (기본값 ±180 조인트 deg 는 기계 범위가 아닙니다)

📷 *(캡처: 모터 설정 · ② 조인트 매핑 표)*

## 5. 애니메이션 업로드

**만드는 곳** : Blender · 리그에서 본 애니메이션을 만들고 export 스크립트로
`.json` 을 뽑습니다 (제작 절차는 리그 쪽 문서)
**파일 내용** : 조인트 이름별 각도 · 50fps(20ms) 한 줄씩 ·
단위는 파일 첫 줄의 `rotation_unit` 이 정합니다 (`rad` 또는 `deg` · 칸이 없으면 deg) · 둘 다 같은 크기로 돕니다 ·
한 단위로 맞추려면 `python scripts/convert_motion_unit.py --to rad 파일.json`

### 5-1. 업로드하는 법

**위치** : `작업` → `애니메이션`

```
1) 「업로드」 로 .json 고르기 (여러 개 가능)
   또는 .json 파일을 애니메이션 화면 아무 데나 끌어다 놓기
2) 서버가 검사  →  목록에 추가  →  3D 계산이 저절로 시작 (로봇 팩이 있을 때)
```

- `.json` 만 받음 · 폴더째 놓기는 안 됨(파일을 골라 놓기)
- 여러 개 중 하나가 실패하면 거기서 중단하고 이유가 뜸 · 앞의 것은 업로드된 채

**거부되는 경우** :

| 메시지 | 할 일 |
|---|---|
| 조인트 매핑이 없는 프로젝트에는… | [4-4](#4-4-조인트-매핑) 먼저 |

| 형식 오류 | export 를 다시 뽑기 · 손으로 고친 파일인지 확인 |
| 지원하지 않는 각도 단위 | 첫 줄 `rotation_unit` 을 `rad` 또는 `deg` 로 |

### 5-2. 목록과 상세

**목록** : `이름` · `길이` · `검사` · `3D 계산` · `재생 목록`(몇 번째에 들었나) · `업로드 날짜` · 이름을 누르면 아래에 상세

**상세** : `길이 · fps · 프레임 수 · 조인트 N개 · 매핑에 있음 M개 · 단위` · 조인트마다 그래프(가로선 = 매핑 범위 · 넘으면 빨갛게)

## 6. 수동 조작

**위치** : `작업` → `수동 조작` · **한 페이지에 두 구획** · ① 전체 페이더 (위) · ② 모터 개별 (아래)
**언제** : 설치 확인 · 방향·범위 점검 · 기준점·한계 잡기 · 손으로 움직여 보고 싶을 때
**머리** : `① 전체 페이더` `② 모터 개별` 바로 가기 · 오른쪽 `초기 위치로` (재생 목록 1번 애니메이션의 초기 위치로 천천히 · 확인 창 `이동`)

### 움직이려면

- **운전 모드가 `수동`** 이어야 합니다 · 스케줄·끔이면 `수동 모드로 전환` 버튼이 같이 뜸
- **재생 중이거나 `초기 위치에서 대기 중`** 이면 거절 · 「… 「정지」를 누른 뒤 수동 조작을 하세요」 → 같이 뜨는 `정지` 또는 맨 위 `정지` 먼저
  (`초기 위치로` 를 누른 뒤에도 이 상태로 기다리므로, 조작하려면 `정지`)
- 조인트 범위 미확인 · 앱솔루트 미확인 · 긴급 정지 · 모터 알람 · 서보 꺼짐 · 매핑에 없는 모터면 거절 · 막힌 이유와 해결 버튼이 그 자리에 뜸
- 정지 · 서보 끄기 · 오류 초기화는 언제나 됨

### 속도 · 모든 수동 조작은 천천히

- 페이더 · 다이얼 · 목표 위치 이동 · 범위 안으로 복귀 · **조인트 2 °/s · 가속 4 °/s²** 를 넘지 않음 (감속비가 달라도 모든 축이 같은 조인트 속도)
- **파랑 = 목표**(찍은 곳 · 바로 옮겨 감) · **회색 = 지금 위치**(천천히 따라옴) · 둘 사이 옅은 막대 = 따라가는 중 · 도착하면 하나로 겹침
- 잘못 찍어도 · 다이얼 한 칸을 크게 해도 한 번에 가지 않고 그 자리까지 이 속도로 감 · **손을 놓아도 목표까지 감**
- 가는 중 멈추려면 `동작 취소` (그 자리에 섬) · 맨 위 `정지` 도 같음 · 수동 조작 화면을 떠나면 그 자리에 섬
- 가는 중 **같은 조작**(같은 페이더를 다시 끌기 · 같은 다이얼에 칸 더하기) = 새 목표로 바꿈 ·
  **다른 조작**(페이더로 가는 중 그 모터 다이얼 · 목표 위치 이동 등) = 거절 「N번 모터 이동 중(페이더) · 도착하거나 「동작 취소」 뒤에 조작하세요」

### 6-1. 전체 페이더

**무엇** : 매핑 줄(「사용」 켜짐)마다 슬라이더 하나 · 손잡이(파랑) = 목표 · 모터는 조인트 2 °/s 로 따라옴 · 놓아도 목표까지 간 뒤 섬

- 범위 = 조인트 매핑의 범위 · 그 밖으로는 안 나감 · 양 끝 숫자가 범위
- 움직이지 않을 때 손잡이 = 실제 위치 · 따라가는 중이면 회색 표시가 지금 위치 · 오른쪽 글 `목표 … · 현재 …`
- 위 `동작 취소` · 페이더 · 다이얼 · 목표 위치 이동을 모두 그 자리에 세움
- 그 모터만 막혀 있으면 줄 끝에 `조작 불가` (마우스를 올리면 이유)
- 다른 화면에서 조인트 매핑을 고쳤다면 거부됨 · 화면 새로 고침 후 다시
- 페이더를 잡으면 ② 다이얼이 몰던 것은 놓음 (반대도 같음) · 놓은 것은 목표까지 가므로 그 모터는 도착 뒤에 다른 조작

📷 *(캡처: 수동 조작 · ① 전체 페이더)*

### 6-2. 모터 개별

**왼쪽 목록** : 모터마다 이름(조인트 이름) · 지금 조인트 ° · `서보 켜짐/꺼짐 · N번 · AC/DXL · 1:감속비` (매핑이 없으면 `매핑 없음`) · 눌러서 고름
**오른쪽** : 고른 모터의 큰 숫자 = 지금 위치 (조인트 ° + 모터 °) · 범위 막대 (`하한 · 0 기준점 · 상한`)

**단위** : 오른쪽 위 `조인트 °` · `모터 °` · 조인트면 한 칸·목표 위치·남은 이동이 조인트 deg (매핑 식으로 모터 deg 로 바꿔 보냄 · 1:150 축에서 한 칸 1° = 모터 150°) ·
매핑 없는 모터는 모터 ° 만 · 단위를 바꾸면 돌리던 것은 그 자리에 섬

**움직이기 · 다이얼**

| 항목 | 무엇 |
|---|---|
| `다이얼` ON/OFF 스위치 | 화면을 처음 열면 **OFF** · 켜야 다이얼과 `◀` `▶` 가 움직임 · 끄면 그 자리에 섬 |
| 다이얼 (가로 띠) | 끄는 만큼 목표(파랑)가 옮겨 가고 모터는 조인트 2 °/s 로 따라옴(오른쪽 = +) · 눈금이 손을 따라 밀림 · 24 px = 한 칸 · 휠 100 px(마우스 한 눈금쯤) = 한 칸 · ← → 키 = 한 칸 · **Shift = 1/10 칸** |
| `◀` `▶` | 한 칸씩 · 길게 누르면 반복 |
| `한 칸` | 한 칸 크기 · 기본 1 · 0.001~360 · 단위는 위에서 고른 것 · 10 으로 해도 한 번에 가지 않고 같은 속도 |
| 옆 글 | `목표 …° · 남은 이동 …° · 천천히(조인트 2 °/s)` · 한계에 닿으면 `… 도달` · 쉬면 `대기` |

- 실시간 전송(50 ms) · 손을 떼도 목표까지 간 뒤 섬
- 목표가 운전 한계(= 조인트 매핑 범위를 환산한 값) 밖이면 한계에서 섬
- 범위 막대 · 회색 = 지금 위치 · 파랑 = 목표

**목표 위치로 이동 (조인트 ° 또는 모터 °)** : 숫자 입력 → `천천히 이동` · 조인트 2 °/s · 4 °/s² (모터 설정 값이 더 느리면 그쪽) · 그 모터가 움직이는 중에는 눌리지 않음(도착 뒤 다시) ·
범위 밖이면 보내지 않고 범위를 알려 줌
**동작 취소** : 다이얼 · 페이더 · 목표 위치 이동을 모두 그 자리에 세움 · 서보는 켠 채 · 늘 누를 수 있음

**하한점 지정 · 기준점 지정 · 상한점 지정** : 지금 위치를 조인트 매핑에 저장 (하한·상한은 범위 · 기준점은 조인트 0°) ·
저장 직후 **`장비에 적용 및 모터 재시작` 을 바로 물음** · 해야 운전 한계(소프트 리밋 · 다이얼·페이더 경계)도 새 기준으로 옮겨짐 ·
안 하면 「운전 한계가 아직 적용되지 않았습니다」 → 나중에 모터 설정 `저장 후 장비에 적용` ·
누를 수 있는 때 = 매핑 줄이 있고 · 모터 설정이 장비에 적용됐고 · 다이얼 이동이 끝났을 때

**서보 칸** (맨 아래 `서보 · 이름`)

| 버튼 | 무엇 |
|---|---|
| `서보 켜기` · `서보 끄기` (다이나믹셀 `토크 켜기` · `토크 끄기`) | 힘 넣기·빼기 · 끄기는 확인 창 |
| `오류 초기화` (다이나믹셀 `재부팅`) | 알람 해제 · 서보는 꺼진 채 → `서보 켜기` |

### 6-3. 범위 밖에 있을 때

위치가 운전 한계 밖이면 빨간 줄 `운전 한계를 벗어나 있습니다` · 다이얼·목표 위치 이동이 막힘 ·

## 7. 재생

**위치** : `운영` → `재생`

**화면 위에서 아래로** : 재생 대상 (`단독` · `그룹 전체`) → 지금 칸 (상태 · 버튼) → (그룹 전체일 때) PC별 재생 상태 →
3D 동시 재생 → 재생 목록 · 반복 → 실행 조인트

### 재생 순서

```
1) 운전 모드  →  「수동」           (스케줄 모드에서는 시작 버튼이 막힘)
2) 재생 목록  →  애니메이션 추가     (아래 선택 칸 + 「추가」 · 또는 애니메이션 화면에서)
3) 재생 대상  →  「단독」 또는 「그룹 전체」
4) 「1회 시작」 또는 「연속 시작」    →  초기 위치로 천천히 → 재생
5) 지금 칸에서 단계(초기 위치 · 재생 · 도착 확인)와 진행 막대 보기
```

### 7-1. 재생 목록

**위치** : `재생 목록 · N` 칸 (애니메이션 화면 오른쪽에도 같은 목록)

- 위에서부터 차례로 재생 · `연속 시작` 이면 마지막 다음에 1번부터 다시 · 끝없이
- **애니메이션 사이마다 다음 애니메이션의 초기 위치로 천천히 이동**합니다 (회차 사이 설정이 무엇이든)
- `1회 시작` = 목록 1번만 한 번
- 아래 선택 칸에서 고르고 `추가` · 같은 파일을 두 번 넣어도 됨 · 최대 50개 · `오류` 파일은 고를 수 없음
- `↑` `↓` 순서 · `삭제` = 목록에서만 빼기 (파일은 남음)
- 재생 중에는 바꿀 수 없음 · 재생 중인 줄은 `재생 중`
- 멈췄다 다시 시작하면 늘 1번부터 · 목록의 파일 하나라도 깨져 있으면 시작이 거절되고 그 파일 이름이 뜸
- 지금 칸에 `목록 2/3 · 연속` 처럼 보임
- 목록은 PC 마다 따로입니다 (자기 조인트 매핑 파일에 저장)

### 7-3. 반복 설정

`1회 시작` 은 다시 하지 않음

- 물리 계산은 서버의 MuJoCo 가 한다 · 브라우저는 자세만 그린다 · three.js 는 저장소 안 사본이라 외부망 불필요

## 8. 여러 대 묶기

**하는 일** : 여러 PC 가 같은 시각에 함께 재생
**한 대만 쓰면** : 이 장 건너뛰기
**어디서** : 처음 한 번 `네트워크·시간·그룹` → `그룹 설정` · 평소 `PC 현황` · 함께 돌리기 `재생` → `그룹 전체`

### 8-1. 그룹 설정 (처음 한 번)

**위치** : `설정` → `네트워크·시간·그룹` → `그룹 설정 (처음 한 번만)` · 각 PC 에서

| 항목 | 규칙 | 예 (1번 / 2번) |
|---|---|---|
| 역할 | 한 대만 `마스터` · 나머지 `슬레이브` | 마스터 / 슬레이브 |
| 그룹 ID | 묶을 PC 끼리 같게 · 영문·숫자로 시작 | `stage-a` / `stage-a` |
| DDS Domain | 묶을 PC 끼리 같게 · 0~101 | `21` / `21` |
| 표시 이름 | 비워 두면 PC ID | `PC A` / `PC B` |
| PC ID | **바꿀 수 없음** · 설치할 때 컴퓨터 이름 | `floating1` / `floating2` |

**저장** : `저장 후 연동 재시작` · 연동 서비스가 몇 초 다시 뜸 · 그룹 재생 중에는 안 됨 ·
같은 그룹에 마스터가 이미 있으면 `마스터가 이미 있습니다` 창 (마스터가 둘이면 그룹 오류로 재생이 정지)

### 8-2. 그룹 참여 스위치

**위치** : `운영` → `PC 현황` 맨 위 `그룹 참여 · ON/OFF`

- **켜면** 같은 그룹 PC 와 같이 시작·정지 · **끄면** 그 PC 는 단독 (스케줄도 단독) · 확인 창 `끄기`
- 처음 켤 때 연동 서비스가 한 번 다시 뜸 · 그룹 ID 가 없으면 「그룹 ID가 없습니다…」 → [8-1](#8-1-그룹-설정-처음-한-번) 먼저
- 그룹 재생이 도는 중에는 못 끔 · 켜고 끈 것은 재부팅해도 그대로
- 홈 「PC 현황」 칸과 PC 카드에 `그룹 참여` / `그룹 미참여` 로도 보임

### 8-3. PC 현황 화면

**위치** : `운영` → `PC 현황` · 머리에 그룹 ID · Domain

**운전 모드 · PC 별** : 같은 네트워크의 로봇 PC 마다 지금 운전 모드(`스케줄` · `수동` · `끔`)와 바꾸기 버튼 ·
그 PC 화면에 따로 들어가지 않아도 됨 · `모두 스케줄` · `모두 수동` 으로 연결된 PC 를 한 번에 · 누르면 확인 창 ·
`연결 안 됨` PC 는 못 바꿈 · 스피커는 운전 모드가 없어 빠짐 · 밤샘 시험처럼 여러 대를 스케줄로 돌릴 때

**PC 카드** : 같은 네트워크의 PC 마다 한 장 (스피커 PC 포함)

| 보이는 것 | 무엇 |
|---|---|
| 이름 · `현재 접속` | 지금 이 화면을 연 PC 는 `현재 접속` · 칸 아래 `현재 화면` |
| 상태 칩 | `그룹 대기` · `재생 중` 같은 지금 단계 · `단독` · `스피커` · `연결 안 됨` · `버전 다름`(커밋만 다름 · 그룹 재생은 됨) · `연동 버전 다름`(연동 약속 번호가 다름 · **그룹에서 빠짐** · 번호가 같이 보임) · `알람` |
| 주소 · 버전 | IP · 코드 버전(짧은 해시) |
| 역할 | `마스터` · `슬레이브` · `스피커` · `그룹 참여` / `그룹 미참여` |
| `화면 열기 ↗` | 그 PC 의 새 화면(`/v2`)을 새 탭에서 · 모드 바꾸기 등은 그 화면에서 (스피커는 스피커 화면) |
| `터미널 ↗` | 그 PC 의 터미널(`:8081`)을 새 탭에서 |

**업데이트 칸**

- `N대 모두 같은 버전입니다` 또는 `N대 중 M대 버전이 다릅니다`
- `모든 PC 업데이트` → 확인 창 `업데이트` · PC 마다 코드 받기 → 빌드 → 다시 시작 (몇 분) · **스피커 PC 도 같이** ·
  재생 중인 PC 는 건너뜀 · 실패한 PC 는 이전 버전으로 되돌아가 계속 동작 · 운영 시간이 아닐 때
- 표 `PC` · `지난 업데이트`(`업데이트 중` · `완료` · `실패 · 이전 버전으로 복구함` · `응답 없음` · `연결 안 됨`) · `버전` · `메모`
- 스피커 줄이 `해당 PC에서 직접 업데이트 필요` 면 · 스피커 카드의 `터미널 ↗` (`:8081`) 에서 `bash ~/robot_web/scripts/install_speaker.sh`

**필수 명단** : 그룹을 시작할 때 와야 할 PC

- 명단에 있는데 빠진 PC 는 `미접속` 으로 남기고 **나머지 PC 로** 시작 · 명단 밖 PC 는 `명단 외` 로 빠짐 · 비어 있으면 연결된 PC 로 시작
- 마스터에서 `현재 연결된 N대로 다시 지정` → 확인 창 `지정` · 모든 PC 가 정상이고 버전이 같을 때
- 버전이 다르면 위 `모든 PC 업데이트`

**모든 PC 일괄 작업** : `시간대 맞추기 (스피커 포함) ›` → [시간대](#네트워크시간) · `그룹 재생 ›` → 재생 화면

📷 *(캡처: PC 현황 · 세 대가 같은 버전 · 그룹 참여 ON)*

### 8-4. 함께 돌리기

**위치** : `운영` → `재생` → 재생 대상 `그룹 전체 · N대`
**N** : 지금 누르면 **실제로 들어갈 PC 수** (마스터 포함) · 빠질 PC 는 그 아래 `빠짐 · floating2(끔 모드) · …` 로 시작 전에 보임 · 도는 중에는 이번 참가 PC 수
**누가 들어가나** : 사람이 누른 그룹 재생은 `수동` · `스케줄` PC 모두 · `끔` PC 와 사람 조작 중(조그 · 페이더 · 단독 재생)인 PC 만 빠짐 ·
스케줄이 켠 그룹 재생은 `스케줄` PC 만 ([2장](#2-운전-모드))
**시작 알림** : `그룹 실행 준비 확인 시작 · 참가 N대 · 빠짐 …`
**시작** : 마스터에서만 · 슬레이브는 `그룹 전체` 를 고를 수 없음 (그룹 재생이 도는 중에는 정지하러 고를 수 있음)
**정지** : 아무 PC 에서나 · `그룹 전체` 를 고르고 `즉시 정지 · 그룹 전체` 또는 `이번 회차 후 정지`
**각 PC 의 애니메이션** : 자기 프로젝트의 재생 목록 · 같은 파일이 아니어도 됨 · 시작 시각만 맞춤 ([7-1](#7-1-재생-목록))
**버튼** : `초기 위치로` · `1회 시작` · `연속 시작` · `이번 회차 후 정지` · `즉시 정지 · 그룹 전체` 가 모든 PC 에 감 · `초기 위치 이동 시간` 도 모든 PC 에

**PC 간 동기화** (`반복` 칸 · 그룹 전체일 때만 보임 · 고르면 저장되고 스케줄 시작도 이 값을 씀)

| 선택 | 무엇 |
|---|---|
| `회차 맞춤 (먼저 끝난 PC가 기다림)` (기본) | 매 회차 모든 PC 가 끝나야 다 같이 초기 위치 → 다음 회차 · 목록이면 n회차 = 각자 목록의 n번째 |
| `각자 재생 (시작만 함께)` | 처음 초기 위치 이동과 1회차 시작만 같이 · 그 뒤로는 PC 마다 제 목록을 제 속도로 · 기다리지 않음 |

`각자 재생` 에서 `이번 회차 후 정지` 는 PC 마다 **제 애니메이션이 끝나는 때** 정지하고, 모두 정지하면 그룹이 풀립니다 ·
그룹을 쓰는 PC 는 **모두 같은 버전**으로 ([8-3](#8-3-pc-현황-화면) `모든 PC 업데이트`) · 다른 버전 PC 는 `버전 불일치` 로 빠짐

**PC별 재생 상태** (`그룹 전체` 일 때) : PC 마다 회차 · 단계 · 진행 · 위에 `시작 편차 N ms`

**1대가 빠져도 나머지는 돕니다** · 시작할 때 아래 PC 는 빼고 나머지로 시작하고 그 줄에 `제외됨 · 이유` 가 뜹니다 ·
마스터 `기록` → `운영 로그` → `그룹` 에도 남습니다 (나중에·원격에서 확인)

| 이유 | 무엇 |
|---|---|
| `모터 설정 없음(재생할 모터가 없는 PC)` | 모터 설정·조인트 매핑을 저장하지 않은 PC · 고장이 아님 · 그 PC 는 건너뛰고 그룹은 계속 |
| `통신 단절` · `응답 지연` · `연결 안 됨` · `미접속` | 꺼짐·네트워크 문제 · 하트비트가 안 오거나 늦음 |
| `알람 · …` | 그 PC 에 드라이브 알람 · 그 PC 에서 해제 |
| `끔 모드` | 그 PC 가 `끔` · PC 현황 `화면 열기 ↗` 로 들어가 모드 변경 |
| `수동 모드` | **스케줄이 켠** 그룹 재생에서만 · 그 PC 가 `수동` (사람이 누른 그룹 재생에는 들어감) |
| `단독 재생 중` · `준비 거절 · 사람 조작 중 · 조그 이동` (`페이더` · `목표 위치 이동` · `단독 재생`) | 그 PC 에서 사람이 움직이는 중 · 그 PC 만 빼고 나머지로 |
| `준비 거절` · `준비 응답 없음` | 시작 준비 단계에서 그 PC 가 거절하거나 답이 없음 · 남은 PC(마스터 포함)는 그대로 시작 |
| `버전 불일치` | PC 현황 `모든 PC 업데이트` |
| `명단 외` | 필수 명단에 없는 PC |

**돌던 중에** 참가 PC 하나가 끊기면 그룹 전체가 정지합니다 · 스케줄 모드면 다음 점검(1분 안)에 끊긴 PC 를 빼고 다시 시작합니다 ·
빠졌던 PC 가 돌아오면 **도는 중에도 다시 들어갑니다** (`회차 맞춤` · 연속 재생일 때) · 지금 회차가 끝나 모두가 초기 위치로 갈 때 같이 가서
**다음 회차부터** 같이 돕니다 · 다른 PC 는 기다리지 않고, 애니메이션 중간부터 끼어들지 않습니다 · 그동안 `참여 준비 중` → `다음 회차부터 참여` ·
`각자 재생` 은 다음 그룹 시작 때 들어갑니다

### 8-5. 한 대만 잠시 빼기

```
1) 그 PC 화면  →  PC 현황  →  「그룹 참여」 OFF   (그룹 재생 중이면 정지한 뒤)
2) 정비
3) 「그룹 참여」 ON
```

**나머지 PC** : 다음 그룹 시작부터 그 PC 없이 돕니다

### 8-6. 오류가 났을 때

**증상** : 상태 줄 빨강 `그룹 오류` · 모든 PC 에 표시
**해제** : 「확인할 일」 창(또는 재생 화면)의 `그룹 오류 해제` 를 **아무 PC 한 대에서만** · 마스터일 필요 없음

| | 무엇 |
|---|---|
| 「확인할 일」 창 닫기 | 창만 닫힘 · 오류는 안 풀림 |
| `그룹 오류 해제` | 오류가 풀림 |
| 드라이브 알람 | 그룹 오류 해제로 안 풀림 · 알람 난 PC 에서 `오류 초기화` |

**잠그지 않는 것** (그룹 오류가 아님 · 해제 버튼 필요 없음 · 스케줄이 다음 점검 1분 안에 다시 시작)

| 상황 | 화면 |
|---|---|
| 마스터 자신이 아직 준비 안 됨 (부팅 직후 앱솔루트 확인 · 모터 상태 대기 · 사람 조작 중) | 「확인할 일」 `그룹 시작이 취소되었습니다` + 이유 |
| 스케줄 · 부팅 직후 준비가 끝나기 전 | 「확인할 일」 `스케줄 시작 대기 중 (N회)` · 준비가 끝나면 스스로 시작 · 3번 넘게 이어지면 빨강 |
| 스케줄 · 시작은 보냈는데 재생으로 이어지지 않음 | `스케줄 시작 거부됨 (N회)` + 이유 · 3번이면 빨강 |
| `프로그램 다시 시작` 을 누름 | 아무것도 안 남음 (사람이 한 재시작은 오류가 아님) |
| 끝난 그룹 실행이 정리되지 않고 남음 | 20초 뒤 스스로 정리 · 다음 시작이 `이전 그룹 실행 정리 확인 중입니다` 로 막히지 않음 |

## 9. 스케줄 걸기

**위치** : `운영` → `스케줄`
**하는 일** : 시각이 되면 시작 · 끝나면 정지
**모드** : 위 막대가 `스케줄` 일 때만 돕니다 · [2장](#2-운전-모드)

### 스케줄 추가

**버튼** : 오른쪽 위 `+ 새 스케줄` → 오른쪽 편집 칸 → `저장`

| 항목 | 무엇 |
|---|---|
| 이름 | 알아볼 이름 · 예 `매장 운영` |
| 시작 · 종료 | PC 현지 시각 기준 |
| 반복 | `매일` · `요일 선택` · `한 번 (날짜 지정)` |

**목록 줄** : 켜기 스위치 (끄면 삭제하지 않고 잠시 중지) · `편집` · `삭제`(되돌릴 수 없음) · 지금 도는 것은 `운영 중`
**이번 주** : 맨 위 요일별 막대 · 오늘 줄에 지금 시각 선

📷 *(캡처: 스케줄 · 이번 주 막대와 편집 칸)*

### 어떻게 도는가

**판단 기준** : 「시각을 지나갔나」가 아니라 **「지금 구간 안인가」**
**점검 주기** : 1분마다
**구간 안인데 멈춰 있으면** : 시작
**구간 밖인데 돌고 있으면** : 현재 회차를 끝내고 정지 → (스케줄 모드면) 아래 「운영 시간이 끝나면」 대로
**구간이 끝날 때 이미 멈춰 있으면** : (스케줄 모드면) 바로 기준점 이동 → 서보 끔 · 구간 끝마다 한 번 · 그룹이면 스케줄 모드 PC 마다

**운영 시간이 끝나면** (목록 칸 아래 선택 · PC 마다 · 그룹이어도 각 PC 가 제 설정대로)

| 선택 | 무엇 |
|---|---|
| `회차가 끝나면 기준점으로 이동 후 서보 끄기` (기본) | 지금 애니를 마친 뒤 기준점(0°)으로 10초 동안 천천히 → 도달 확인 → 서보 끔 (AC 서보는 브레이크 · 다이나믹셀은 토크 끔) |
| `회차가 끝난 자세 유지 (서보 켜짐)` | 그 자세에서 서보 켠 채 정지 |

- **주차가 안 되면 끄지 않습니다** · 알람·재생 오류·도달 확인 실패면 서보를 켠 채 그 자리에 두고 `최근 결과 · …` 줄에 이유가 뜹니다
- 멈춰 있던 로봇은 서보가 켜져 있어야 주차합니다 · 꺼진 모터가 있으면 억지로 켜지 않고 그대로 둡니다 · 이미 다 꺼져 있거나 끌 모터가 없으면(아래 모터별 체크) 아무것도 안 함
- **다음 시작** (스케줄·수동·그룹 모두) 때 여기서 끈 모터만 다시 켜고, 켜진 것을 확인한 뒤 초기 위치 이동 → 재생 · 사람이 손으로 끈 서보는 그대로 둡니다
- 모터마다 끄지 않게 하려면 `모터 설정` → 그 모터 설정 칸의 `스케줄 모드에서 운영 시간이 끝나면 서보 끄기` 체크를 풉니다 (다이나믹셀은 브레이크가 없어 처질 수 있는 축이면 끄세요)
- 수동·끔 모드에서 구간이 끝나면 정지만 합니다 (사람이 만지는 중일 수 있어서)

이 방식이라 **놓치는 일이 없습니다.**

| 일어난 일 | 결과 |

### 터미널 · PC 성능

**위치** : `기록·도구` → `터미널 · PC 성능` · 위 탭 `터미널` · `PC 성능 (btop)` · 오른쪽 `새 창 ↗`

**터미널** : 접속한 PC 의 셸(`bash`)을 브라우저 안에서 그대로 연다 · 작업 폴더에서 시작 ·
다른 PC 의 브라우저에서 그 PC 주소로 들어와 `git pull` · 로그 보기 · 재시작 명령 등을 칠 수 있음
**구조** : 별도 서비스 `motion-terminal.service` (`ttyd` · 포트 8081) · **프로그램을 다시 빌드·재시작해도 안 끊김**
**계정** : 프로그램을 돌리는 계정

```
1) 탭 열기                          →  바로 셸
2) 코드 받기 + 다시 빌드            →  bash scripts/install.sh   (화면 위 상자에 적혀 있음)
3) 빌드 동안 웹 화면은 잠깐 끊김    →  터미널은 그대로 · 끝나면  설치 완료
```

| 상황 | 뜻 · 할 일 |
|---|---|
| 화면이 비어 있음 · 연결 거부 | `systemctl --user status motion-terminal.service` · 없으면 `sudo apt install ttyd` 후 `bash scripts/install.sh` |
| 글자가 안 쳐짐 | ttyd 1.7 이상(우분투 24.04)은 기본 읽기 전용 · 실행 스크립트가 `-W` 를 자동으로 붙임 · `systemctl --user restart motion-terminal.service` |

**알아둘 것**
- 이 화면을 열 수 있는 사람은 누구나 그 PC 에서 명령을 실행할 수 있습니다 · 외부망에 노출된 PC 는
  `systemctl --user disable --now motion-terminal.service` 로 끄세요
- 설치 스크립트는 터미널 서비스를 **멈추지 않습니다** · 설치를 치고 있는 창이 그 서비스일 수 있어서입니다

**PC 성능 (btop)** : 접속한 PC 의 CPU·메모리·프로세스를 `btop` 화면 그대로 · 다른 PC 의 브라우저에서도 보임
**구조** : 별도 서비스 `motion-btop.service` (`ttyd` · 포트 8080) · 설치 스크립트가 `btop`·`ttyd` 가 있을 때 자동 등록

| 상황 | 뜻 · 할 일 |
|---|---|
| 화면이 비어 있음 · 연결 거부 | `systemctl --user status motion-btop.service` · 없으면 `sudo apt install btop ttyd` 후 `bash scripts/install.sh` |

- `<PC 이름>만 업데이트` · 몇 분 · 재생 중이면 안 함 · 실패하면 이전 버전으로 되돌아가 계속 동작 · 같은 그룹 PC 는 버전이 같아야 함께 재생
- 새 시스템 패키지가 필요한 업데이트는 그 PC 터미널에서 `bash scripts/install.sh`

**이전 UI 에만 있는 것** : 바탕화면 바로가기 만들기 (예전 「시스템 정보」 화면)

**확인만** : 상태 줄이 🟢 인지 · PC 현황에서 모든 PC 가 정상인지

### PC 를 바꿀 때 (고장 · 교체)

```

5) 기준점 확인 (같은 로봇이면 그대로 · 모터를 바꿨으면 다시 캡처)

```
1) 설정 → 네트워크·시간·그룹 → 시간대
2) 현지 시간대 고르기  →  「모든 PC에 적용 (스피커 포함)」

**터미널로 할 때** : `sudo timedatectl set-timezone <지역/도시>` → `bash scripts/install.sh` (프로그램 다시 설치)
**안 하면** : 스케줄이 옛 나라 시각으로 돎
**스케줄 시각** : 고칠 필요 없음 · 현지 시각으로 해석됨

```
1) 원인 해결
2) 프로그램 다시 시작    (「확인할 일」 창 · 또는 네트워크·시간·그룹 → PC 정보)
3) 상태 줄이 🟢 인지 확인
```

**주의** : 긴급 정지는 **다시 시작 전까지 안 풀립니다**
**다이나믹셀 축** : 긴급 정지 = 토크 끔 · 브레이크가 없어 처짐 · 위치 값은 전원이 있으면 유지(바퀴 수 포함) · 재시작 후 초기 위치 이동으로 복귀 · AC 서보는 브레이크 체결로 처짐 없음

### MINAS 드라이브 값을 명령어로 보기·바꾸기

**언제** : 리밋 스위치(구동 금지 입력)를 끄거나 켤 때 · 입력 핀을 바꿀 때 · 화면에 없는 값
**주의** : 잘못 쓰면 그 방향으로 못 움직이거나 알람(Err33 · Err38) · **값을 모르면 쓰지 말 것** ·
출처 Panasonic MINAS A6B EtherCAT 기능 사양 SX-DSV03241 R10.0 p.26-29 · p.155-157 · 통신 사양 SX-DSV03242 p.77

```bash
# 1) 모터 제어를 먼저 멈춘다 (모터 검색과 같은 상태)
systemctl --user stop motion-motor.service

# 2) 읽기 · <위치> = 슬레이브 위치 (ethercat slaves 로 확인)
ethercat upload   -p <위치> -t uint32 0x3400 0      # SI1 입력 핀 기능 (… 0x3407 = SI8)
ethercat upload   -p <위치> -t int16  0x3504 0      # Pr5.04 리밋 스위치 설정

# 3) 리밋 끄기 = POT/NOT 이 붙은 핀을 무효(00h) 로 (예 SI2)
ethercat download -p <위치> -t uint32 0x3401 0 0x00000000

# 4) EEPROM 에 저장 ("save") · 최대 10초 · 그동안 전원 끄지 말 것
ethercat download -p <위치> -t uint32 0x1010 1 0x65766173

# 5) 드라이브 제어 전원을 껐다 켠다 (입력 핀은 그래야 반영) → 모터 제어 다시 켜기
systemctl --user start motion-motor.service
```

| 값 | 뜻 |
|---|---|
| 입력 핀 값 형식 | `00 TT VV PP` (토크 · 속도 · 위치 모드별 기능 번호) · 보통 셋 다 같게 · 예 `00818181h` = POT b접점 |
| 기능 번호 | 무효 `00h` · POT(정방향 리밋) `01h`(a접점) / `81h`(b접점) · NOT(역방향 리밋) `02h` / `82h` · E-STOP `14h` / `94h` |
| 금지 | 같은 기능을 두 핀에(Err33) · POT 를 SI5·SI7 에 · NOT 을 SI5·SI6 에(Err33.8) |
| Pr5.04 | 0 = 드라이브 감속 정지 · **1 = EtherCAT 감속 정지(권장 · 리밋 살아 있음)** · 2 = Err38 알람 · 「사용 안 함」 값은 없음 |

**파라미터 (고급) · 화면에서 보기·쓰기** (`모터 설정` → 모터 줄 누르기 → 맨 아래 `파라미터 (고급)` 펼치기 · 위 명령어 대신)

- `드라이브에서 읽기` · 자주 보는 값(게인 · 앱솔루트 · 리밋 스위치 · 브레이크 · 정지 방법 · 입력 핀 SI1~8 · CiA402)을 **드라이브 현재값 · 부팅 시 적용값 · 팩토리값** 으로 한 표에 · 모터 프로그램을 멈추지 않음
- `부팅 시 적용값과 다름` = 재시작하면 부팅 값으로 돌아감 · `팩토리값과 다름` = 누가 바꾼 값(마우스를 올리면 팩토리값)
- 직접 읽기 · `Pr5.04` · `0x3504` · `0x607D:2` 처럼 적고 형식(int16 · uint32 …) → `읽기`
- 쓰기 · `쓰기 잠금 해제` → 새 값 → `쓰기`(확인 창) → 되읽기 · **드라이브 RAM 에만**(전원을 끄면 사라짐 · 남기려면 `드라이브 저장(EEPROM)`) · 모터가 움직이는 동안은 거절
- 여기서 못 쓰는 것 · EEPROM 저장 · 앱솔루트 방식 · 다회전 클리어(전용 버튼) · 제어 워드 · 운전 모드 · 목표 · PDO 배선 · 토크 오프셋 0x60B2(쓰지 않기로 함)
- 리밋 스위치를 끄려면 · 그 SI 핀 입력 선택(Pr4.0x)을 0 으로 쓰고 `드라이브 저장(EEPROM)` → **드라이브 제어 전원을 껐다 켬**(입력 핀은 그래야 반영)

**화면으로 되는 것** (`모터 설정` → 모터 표에서 줄 누르기 → 설정 칸 `드라이브 관리` · 명령어 대신)

| 버튼 | 무엇 | 끝나면 |
|---|---|---|
| `드라이브 저장(EEPROM)` | 드라이브 현재값을 드라이브 안(EEPROM)에 · 전원을 꺼도 남게 (위 4번과 같음) | 그대로 사용 |
| `앱솔루트 설정` | Pr0.15 를 0(절대)으로 · 전원 재투입 안내까지 단계별 ([4-3](#4-3-앱솔루트-필수)) | 기준점 다시 캡처 |
| `다회전 클리어` | 엔코더 회전 수 기록 지움 (0x4D01 = 0x0031 → 0x4D00:01 bit9) → 0x4D00:01 되읽기 · bit9 아니면 실패 · **서보 끔일 때만** | **드라이브 전원 재투입 → 기준점 다시 캡처** · 그 전엔 재생 금지 |

셋 다 모터 프로그램을 몇 초 멈췄다가 다시 띄웁니다 (모터 검색과 같은 길) · 재생 중이거나 축이 움직이면 거절 ·
그 자리에 MINAS 가 실제로 있는지 확인한 뒤 씁니다 · 기록은 운영 로그(시스템) ·
Pr0.15 를 0 이 아닌 값(1 인크리멘털 · 2 · 3 · 4)으로 바꾸는 것은 `이전 UI` 모터 설정의 `앱솔루트 방식` 에만 있습니다 (이 현장은 늘 0)

### MINAS 드라이브 게인

**기본** : 로봇을 **조립한 뒤**에는 드라이브의 **실시간 자동조정을 켜 둔 채** 씁니다 (Pr0.02 ≠ 0) · 관성비와 게인을 드라이브가 알아서 맞춤
**떨리면** : 그 축만 자동조정을 끄고(Pr0.02 = 0) 관성비(Pr0.04)를 손으로 맞춘 뒤 EEPROM 저장 · 화면에는 아직 이 칸이 없어 명령어로 (위 1·4·5번 순서와 같음)

| 값 | 뜻 |
|---|---|
| Pr0.02 (`0x3002`) | 실시간 자동조정 · 0 = 끔 · 0 아닌 값 = 켬(종류는 A6B 매뉴얼) |
| Pr0.03 (`0x3003`) | 강성 · **자동조정이 정하지 않음** · 높으면 떨림·소리 · 낮으면 늦게 따라와 오차 · 낮은 값부터 올려 보기 |
| Pr0.04 (`0x3004`) | 관성비(%) · 모터가 돌리는 관성 ÷ 모터 자체 관성 · 자동조정이 켜져 있으면 드라이브가 계속 바꿈 |

```bash
ethercat upload   -p <위치> -t uint16 0x3004 0       # 관성비 읽기 (자동조정이 잡은 값)
ethercat download -p <위치> -t uint16 0x3002 0 0     # 자동조정 끔
ethercat download -p <위치> -t uint16 0x3004 0 137   # 관성비 직접 (예 137)
```

**알아둘 것**
- **부하 없는 책상 위(벤치)에서는 자동조정을 켜 두지 않기** · 관성 추정이 흔들려 ±2° 헌팅이 난 적 있음 (2026-10-07 · 10-13 관성비가 93 으로 낮게 잡힌 뒤에만 남)
- **자동조정이 켜져 있으면 드라이브가 추정한 관성비를 약 30 분마다 EEPROM 에 스스로 저장**(Pr0.04 · 6.07~6.09 · 6.50 · A6 매뉴얼 p323 · 실물 확인 2026-10-13 U-2) · `드라이브 저장(EEPROM)` 을 안 눌러도 남고 · 손으로 쓴 관성비도 30 분 뒤 추정값으로 덮인다 · 다음 전원부터 그 값에서 추정을 이어 감 · 그래서 벤치 값이 남아 있어도 조립 뒤 자동조정이 다시 잡는다(몇 분 움직여 보기)
- 동작이 아주 느리고 멈춰 있는 시간이 길면 관성 추정이 오래 떠다닐 수 있음 · 조립 뒤 실제 애니메이션을 몇 번 돌려 본 다음 판단
- 목 상하는 머리 무게가 늘 걸리는 축 · 자동조정의 수직축 종류가 맞을 수 있음 (값은 A6B 매뉴얼 확인)
- 끈 뒤에도 왕복이 남으면 그 축 서보를 껐다 켜면 끊김
