## 1. 시작하기

**이 문서를 웹에서 보기** : `운영` → `사용법` · 설치법도 같은 자리에 있습니다

**주소** : `http://localhost:8000`
**다른 PC 에서** : `http://<그 PC 주소>:8000` · 예 `http://172.16.21.10:8000`

### 화면 구성

**묶음** : 3개 · 그 아래에 탭

| 묶음 | 탭 |
|---|---|
| 운영 | 실시간 모니터링 · 재생 기록 · 서보 에러 관리 · 로그 · PC 성능 · 터미널 · 사용법 |
| 실행 | 애니메이션 재생 · 수동 조작 · PC 연동 설정 |
| 설정 | 모터 관리 · 프로젝트 관리 · 시스템 정보 |

**맨 위 오른쪽** : 운전 모드 세그먼트(`스케줄 | 수동 | 오프`) ·
`📅 재생 스케줄` 버튼 · 스케줄러 상태 딱지 · `전체 동작 정지` · `긴급 정지`

📷 *(캡처: 화면 맨 위 · 묶음 3개와 모드 세그먼트)*

### 말 두 개만 알면 됩니다

| 말 | 뜻 |
|---|---|
| **모터** | 실제 장비 · 번호(0, 1, 2 …)로 부름 |
| **조인트 이름** | 움직임의 이름 · **Blender 본 이름 그대로** · 예 `Neck_Yaw` |

조인트 이름과 모터를 맺는 것이 **조인트 매핑**입니다 · [4장](#4-모터-관리).
애니메이션 파일은 조인트 이름으로 값을 담고, 재생할 때 연결을 따라
모터로 갑니다 · 연결에 없는 조인트 이름은 조용히 무시됩니다 (한 파일을 여러
PC 에 넣어도 각자 제 조인트 이름만 돌립니다).

### 딱지 색

|---|---|
| 🟢 초록 | 정상 · 시각이 되면 돎 |
| 🟡 노랑 | 돌아야 하는데 못 돎 |

| ⚫ 회색 | 스케줄이 손대지 않음 (수동·오프) |

**이유 보기** : 딱지에 마우스 올리기

### 화면 맨 위 버튼

## 2. 운전 모드

**위치** : 화면 맨 위 세그먼트 `스케줄 | 수동 | 오프` · 어느 화면에서든 한 번에

| 모드 | 스케줄 | 사람 조작 (재생·조그·페이더) | 쓰임 |
|---|---|---|---|
| **스케줄** | 돌림 | 됨 | 평소 전시 |
| **수동** | 멈춤 | 됨 | 정비 · 시험 · 애니메이션 교체 |
| **오프** | 멈춤 | **전부 차단** | 사람이 장비에 붙어 일할 때 |

**오프가 막는 것** : 조그 · 페이더 · 재생 시작 · 초기 위치 이동 · 그룹 시작
**오프가 안 막는 것** : 정지 · 긴급 정지 · 서보 켜고 끄기 · 알람 해제 · 조회
**오프에서 서보** : 켠 채 그 자리를 **버티고** 있습니다 · 힘을 빼려면 서보 끄기를 따로

**위험한 방향은 묻습니다** : 스케줄로 갈 때(운영시간이면 곧바로 재생될 수
있음) · 오프로 갈 때 · 수동으로는 바로 갑니다

**여러 대를 묶었을 때** : 모드는 마스터에서만 바꿀 수 있고 슬레이브는 잠김

## 4. 모터 관리

**위치** : `설정` → `모터 관리` · 한 화면에서 1→4 차례로
**하는 일** : 모터를 찾아 등록하고 · 모터별 운전 한계를 정하고 · 조인트 이름을 맺기

### 순서

```
1) 1. 장비 검색              →  전체 모터 검색
2) 2. 검색 결과 확인 및 모터 편집  →  이름·운전 속도·드라이브 설정
3) 3. 조인트 매핑             →  조인트 이름 ↔ 모터 · 감속·기어비 · 기준점 · 최소·최대
4) 맨 아래 바                 →  저장  →  (필요할 때) 장비에 적용 · 모터 재시작
```

### 4-0. 다이나믹셀 사전 세팅 (Dynamixel Wizard · 1회)

AC 서보(MINAS)는 이 프로그램이 부팅 때 운전 값(동작 모드 · 속도 · 가감속 · 한계 · 브레이크)을 드라이브에 씁니다 ·
다이나믹셀은 **부팅 때 쓰는 값이 둘뿐**(Torque Enable 0 · Operating Mode 4)이라 나머지는 Dynamixel Wizard 로 미리 넣어야 합니다

| 항목 | 값 | 비고 |
|---|---|---|
| ID | 같은 포트 안에서 고유 · 0~252 | 검색은 이 범위만 봄 |
| Baud Rate | 1,000,000 | 프로그램 고정값 · 다른 값이면 검색 안 됨 |
| Protocol | 2.0 | X 시리즈 기본 |
| Operating Mode | 4 (Extended Position) | 프로그램이 재시작마다 다시 씀 · Wizard 값이 달라도 4 로 바뀜 |
| Profile Velocity · Profile Acceleration | 원하는 속도·가속 | 장치 저장값 그대로 사용 · **0 이면 무제한 속도** |
| Shutdown · Return Delay Time 등 | 장치 기본값 또는 현장 값 | 프로그램이 쓰지 않음 |

**오류가 났을 때** : 과부하·과열·전압 오류(Hardware Error)는 모니터링 「오류」 칸에 이름으로 표시 · 웹에서 지우는 수단은
없음 · 원인 제거 → 전원 재투입 → 「장비에 적용 · 모터 재시작」 · 「서보 에러 관리」 등급은 MINAS 전용

### 4-2. 모터 편집

**위치** : `2. 검색 결과 확인 및 모터 편집`
**방법** : 표에서 줄을 누르고 아래 버튼 · 이름과 **운전 속도 · 드라이브 설정**은 표에서 바로 고침

**운전 속도 (모터 deg/s)** : 모터마다 따로 · 빈 칸이면 드라이버 기본값 ·
흐린 숫자 = 실행 중인 모터 설정 파일의 값

**하한·상한은 여기서 안 고칩니다** : 원본은 [4-3 조인트 매핑](#4-3-조인트-매핑)의
최소·최대 하나 · 매핑을 저장하면 모터 deg 로 환산돼 모터 설정에 들어갑니다 ·
`상세 설정 표`에는 읽기 전용으로 보입니다

**드라이브 설정 (MINAS)** :

| 칸 | 무엇 | 값 |
|---|---|---|
| 브레이크·정지 (ms) | 멈춘 채 서보 OFF → 브레이크가 잡힐 때까지 전류 유지 | 0~10000 |
| 브레이크·동작 (ms) | 도는 중 서보 OFF → 브레이크 신호까지 | 0~10000 |
| 과부하율 읽기 | 모니터링에 과부하율 표시 · 드라이브 Ver1.03 이상만 | 끔 / 켬 |
| 앱솔루트 (읽기) | 엔코더 방식 · **보여 주기만** · 0 절대 / 1 인크리멘털 / 2 절대·넘침 무시 / 3 한 바퀴 절대 / 4 연속 회전 | 바꾸기는 EEPROM 저장 기능과 함께 (준비 중) |

- 빈 칸 · 첫 항목 「유지」 = 드라이브에 있는 값을 그대로 둠
- 흐린 글씨 = **마지막 `전체 모터 검색` 때 드라이브에서 읽은 값** · 검색 전이면 「검색 후 표시」 · 못 읽으면 「읽기 실패」
- **리밋 스위치 · 입력 핀은 화면에 없습니다** · 필요하면 명령어로 ([12장 · MINAS 명령어](#minas-드라이브-값을-명령어로-보기바꾸기))
- 값의 뜻은 Panasonic 매뉴얼 기준 (SX-DSV03241 R10.0) · 예전 화면은 앱솔루트 0/1 과 리밋 스위치 「1 사용 안 함」이 매뉴얼과 달랐습니다

| 버튼 | 무엇 |
|---|---|
| `선택 모터 추가` | 이 프로젝트에서 쓰겠다고 등록 |
| `모델·운전 프로필 설정` | 모터 종류·운전값 지정 |
| `선택 모터 사용상태 변경` | 잠시 안 쓰게 |
| `모터 번호 정렬` | 번호를 차례로 |
| `선택 모터 삭제` | 등록 취소 |
| `선택 모터 검색값 반영` | 검색된 모델·일련번호·연결정보를 덮어쓰기 |
| `EEPROM Alias 변경` | 드라이브에 고유 번호 적기 · 랜선 순서가 바뀌어도 같은 모터로 인식 |

**상세 설정 표 탭** : 원본 값(speed · 가감속 · 프로필 등)을 직접 고치는 곳 ·
**모터 목록과 상세 표를 같이 고친 채로는 저장되지 않습니다** · 한쪽을
저장한 뒤 다른 쪽을 고치세요

### 4-3. 조인트 매핑

**위치** : `3. 조인트 매핑`
**하는 일** : 조인트 이름(= Blender 본 이름)를 모터에 맺고 변환값을 정함
**언제** : 애니메이션을 올리기 **전에** · 연결이 없으면 애니메이션을 받지 않습니다

```
1) 조인트 매핑 편집   →  자동 생성
2) 줄마다 조인트 이름을 Blender 본 이름으로  (예 Neck_Yaw · Eye_Pitch)
3) 감속·기어비·반전·최소·최대 입력
4) 기준점 캡처   →  지금 모터 위치가 그 조인트 이름의 0° 가 됨
5) 맨 아래 「저장」 (검증 → 통과하면 저장 · 결과는 「검증 결과」 칸)
```

| 칸 | 무엇 |
|---|---|
| 조인트 이름 | Blender 본 이름 그대로 · 옛 `1-1` 식 이름도 그대로 동작 |
| 모터 | 이 조인트 이름이 움직일 모터 번호 |
| 감속·기어비 | 모션 1° = 모터 몇 ° · 감속기·외부 기어·벨트 포함 · 예 목 좌우 1:100 이면 `100` · 다이나믹셀도 같은 칸 (1 고정 아님) |
| 반전 | 방향이 반대면 켬 · Blender 쪽은 고치지 않음 |
| 기준점 | 모션 0° 일 때의 모터 위치 · `기준점 캡처`로 채움 |
| 초기 위치 | 재생 전에 먼저 옮겨 둘 자세 · `첫 프레임` = 애니메이션 첫 줄 값 (없으면 0°) · `직접 지정` = 옆 「지정 값」 · `기준점` = 늘 모션 0° |
| 지정 값 | 「직접 지정」일 때 이동할 조인트 deg · 다른 방식이면 보여 주기만 |
| 최소·최대 | 조인트 이름이 움직여도 되는 범위 (deg) · **리밋의 유일한 원본** · 재생 클리핑 · 페이더 범위 · 모터 운전 한계(AC 서보 드라이브 soft limit · 다이나믹셀은 아래 「다이나믹셀 리밋」)가 전부 이것 |

**최소·최대 → 모터 운전 한계** : 저장하면 `기준점 + (값 + offset) × 배율 × 방향 × 감속·기어비` 로
모터 deg 를 계산해 모터 설정에 넣습니다 · 드라이브 반영은 `장비에 적용 · 모터 재시작` 후 ·
수동 조작 썸휠의 `− limit` `+ limit` 도 여기(최소·최대)에 저장됩니다

**다이나믹셀 리밋** : 다이나믹셀은 Extended Position(멀티턴) 모드로 돌아 장치의 Min/Max Position Limit 이
적용되지 않고, 설정 파일(`config/dynamixel_*.yaml`)도 한계를 장치에 쓰지 않습니다 · 한계는 소프트웨어가 지킵니다 ·
① 수동 조그·절대 이동·페이더 → 환산한 운전 한계 밖이면 보내지 않음 ② 재생 → 계획 단계에서 범위 안으로 자르고,
보내는 단계에서도 밖이면 경계값으로 보냄(로그 경고) · 한 바퀴(±180°) 제한은 없으며 장치 범위(±256 바퀴) 안에서
여러 바퀴를 돌 수 있습니다 · **감속·기어비가 1 이 아니면 모터가 여러 바퀴 돌 수 있으므로 최소·최대를 반드시 실제
기계 범위로 넣으세요** (기본값 ±180 조인트 deg 는 기계 범위가 아닙니다)

**기준점 캡처가 눌리려면** : 4-4 의 적용이 끝나 장비가 돌고 있어야 합니다

📷 *(캡처: 3. 조인트 매핑 · 조인트 이름과 모터가 맺어진 표)*

### 4-4. 저장하고 장비에 넣기

## 6. 수동 조작

**위치** : `실행` → `수동 조작`
**언제** : 설치 확인 · 방향·범위 점검 · 손으로 움직여 보고 싶을 때

### 순서

```
1) 1. 시험할 모터 선택
2) 2. 서보 준비        →  서보 켜기  (오류 있으면 오류 초기화)
3) 페이더 또는 4. 동작 명령
4) 결과 확인
```

### 페이더 (실시간 드래그)

**위치** : 서보 준비 바로 아래 `페이더 · 실시간 드래그`
**무엇** : 조인트마다 슬라이더 하나 · **잡고 끄는 동안만** 모터가 따라오고 ·
**놓으면 그 자리에 섭니다**

- 범위 = 조인트 매핑의 최소·최대 · 그 밖으로는 안 나감
- 잡지 않은 페이더는 실제 모터 위치를 따라 움직임
- 재생이 돌고 있는 조인트 이름은 재생이 우선 · 페이더 명령은 거부됨
- 조인트 매핑을 다른 화면에서 고쳤다면 거부됨 · 화면 새로고침 후 다시
- 오프 모드에서는 동작하지 않음

📷 *(캡처: 수동 조작 · 페이더 줄)*

### 조그 (버튼으로 조금씩)

**위치** : `4. 동작 명령` → 조그 모드

| 항목 | 무엇 |
|---|---|
| 조그 이동량 (도) | 한 번 누를 때 움직일 각도 |
| **조그 단위** | **조인트 deg 기준** 이 기본 · 감속·기어비와 방향이 적용됨 · 끄면 모터 deg 그대로 |
| `- 방향` `+ 방향` | 그 방향으로 한 번 |

**조인트 deg 기준이면** : 목 좌우(1:100)에서 `1` 을 치면 조인트 이름이 1° (모터는 100°) 돕니다 ·
끄면 모터축이 1° 돌아 조인트 이름은 거의 안 움직입니다

### 썸휠 · 목표 위치 이동 (모터 deg)

**위치** : `4. 동작 명령` → 조그 모드 아래 썸휠(가로 드럼 · 2026-10-04 · 원형 다이얼 대체)

| 항목 | 무엇 |
|---|---|
| `썸휠` ON | 띠를 좌우로 끌면 끌린 만큼 모터가 움직임(오른쪽 = +) · 24 px = 한 칸 · 위 `◀` `▶` = 한 칸(길게 누르면 반복) · 휠·←→ 키 = 한 칸 · 한 칸 = 입력한 모터 deg |
| `썸휠` OFF | `목표 위치 (모터 deg)` 입력 → `이동` (또는 Enter) · 속도·가속은 모터 설정 한계를 따름 |
| 모터 위치 | 썸휠·목표 칸 공통 · 목표 칸은 처음에 지금 위치로 채워짐 |
| `동작 취소` | 남은 썸휠 이동을 버리고 움직이는 조그·이동을 멈춤 · 서보 ON 유지 · 늘 누를 수 있음 |
| `− limit` `기준점 지정` `+ limit` | 지금 위치를 조인트 매핑에 저장 |

- 목표가 모터 운전 한계(= 조인트 매핑 환산값) 밖이면 보내지 않음
- 옛 「동작 모드」(출력축 도 · 감속·기어비 손입력)는 없앴습니다

### 범위 복귀

### 어떻게 도는가

**판단 기준** : 「시각을 지나갔나」가 아니라 **「지금 구간 안인가」**
**점검 주기** : 1분마다
**구간 안인데 멈춰 있으면** : 시작
**구간 밖인데 돌고 있으면** : 현재 회차를 끝내고 정지 → (스케줄 모드면) 아래 「운영 시간이 끝나면」 대로

**운영 시간이 끝나면** (스케줄 창의 선택 · PC 마다 · 그룹이어도 각 PC 가 제 설정대로)

| 선택 | 무엇 |
|---|---|
| `기준점으로 이동 후 서보 OFF` (기본) | 지금 애니를 마친 뒤 기준점(0°)으로 10초 동안 천천히 → 도달 확인 → 서보 OFF (AC 서보는 브레이크 · 다이나믹셀은 토크 OFF) |
| `마지막 자세에서 서보 켠 채 정지` | 옛 동작 |

- **주차가 안 되면 끄지 않습니다** · 알람·재생 오류·도달 확인 실패면 서보를 켠 채 그 자리에 두고 스케줄 창에 이유가 뜹니다
- **다음 시작** (스케줄·수동·그룹 모두) 때 여기서 끈 모터만 다시 켜고, 켜진 것을 확인한 뒤 초기 위치 이동 → 재생 · 사람이 손으로 끈 서보는 그대로 둡니다
- 모터마다 끄지 않게 하려면 `모터 관리` 상세 설정의 `끝나면 서보 OFF` 체크를 풉니다 (다이나믹셀은 브레이크가 없어 처질 수 있는 축이면 끄세요)
- 수동·오프 모드에서 구간이 끝나면 멈추기만 합니다 (사람이 만지는 중일 수 있어서)

이 방식이라 **놓치는 일이 없습니다.**

| 일어난 일 | 결과 |
|---|---|
| 개장 시각에 PC 가 꺼져 있었음 | 켜면 1분 안에 시작 (구간 안이므로) |
| 한낮에 재부팅 | 다시 뜨면 이어서 시작 |
| 정전으로 멈춤 | 복구되면 시작 |
| 종료 시각을 넘겨 재시작 | 안 시작함 (구간 밖이므로) |

### 시각 정하기

**자정 넘기기** : 종료가 시작보다 이르면 다음 날로 봄 · `23:00 ~ 01:00` = 그날 23시 ~ 다음 날 1시
**여러 개 겹칠 때** : **먼저 시작한** 스케줄을 따름
**끄기** : 스케줄마다 켜고 끌 수 있음 · 지우지 않아도 됨

### 여러 대를 묶었을 때

**판단하는 PC** : 마스터 한 대만
**슬레이브** : 스케줄이 아무 일도 안 함 · 마스터가 보내는 그룹 실행만 따름
**설정하는 곳** : 마스터에서만 · 슬레이브는 화면이 잠김

### 알아둘 것

**PC 시각** : 창 위쪽 `🕒 PC 시각` 에 시간대가 같이 표시 · 설치한 나라와 다르면 엉뚱한 시각에 돎

### MINAS 드라이브 값을 명령어로 보기·바꾸기

**언제** : 리밋 스위치(구동 금지 입력)를 끄거나 켤 때 · 입력 핀을 바꿀 때 · 화면에 없는 값
**주의** : 잘못 쓰면 그 방향으로 못 움직이거나 알람(Err33 · Err38) · **값을 모르면 쓰지 말 것** ·
출처 Panasonic MINAS A6B EtherCAT 기능 사양 SX-DSV03241 R10.0 p.26-29 · p.155-157 · 통신 사양 SX-DSV03242 p.77

```bash
# 1) 모터 제어를 먼저 멈춘다 (모터 검색과 같은 상태)
systemctl --user stop motion-motor.service

# 2) 읽기 · <위치> = 슬레이브 위치 (ethercat slaves 로 확인)
ethercat upload   -p <위치> -t uint32 0x3400 0      # SI1 입력 핀 기능 (… 0x3407 = SI8)
ethercat upload   -p <위치> -t int16  0x3504 0      # Pr5.04 리밋 스위치 설정

# 3) 리밋 끄기 = POT/NOT 이 붙은 핀을 무효(00h) 로 (예 SI2)
ethercat download -p <위치> -t uint32 0x3401 0 0x00000000

# 4) EEPROM 에 저장 ("save") · 최대 10초 · 그동안 전원 끄지 말 것
ethercat download -p <위치> -t uint32 0x1010 1 0x65766173

# 5) 드라이브 제어 전원을 껐다 켠다 (입력 핀은 그래야 반영) → 모터 제어 다시 켜기
systemctl --user start motion-motor.service
```

| 값 | 뜻 |
|---|---|
| 입력 핀 값 형식 | `00 TT VV PP` (토크 · 속도 · 위치 모드별 기능 번호) · 보통 셋 다 같게 · 예 `00818181h` = POT b접점 |
| 기능 번호 | 무효 `00h` · POT(정방향 리밋) `01h`(a접점) / `81h`(b접점) · NOT(역방향 리밋) `02h` / `82h` · E-STOP `14h` / `94h` |
| 금지 | 같은 기능을 두 핀에(Err33) · POT 를 SI5·SI7 에 · NOT 을 SI5·SI6 에(Err33.8) |
| Pr5.04 | 0 = 드라이브 감속 정지 · **1 = EtherCAT 감속 정지(권장 · 리밋 살아 있음)** · 2 = Err38 알람 · 「사용 안 함」 값은 없음 |

**화면으로 되는 것** (`모터 관리` 상세 설정 · AC 서보 줄의 정비 버튼 · 명령어 대신)

| 버튼 | 무엇 | 끝나면 |
|---|---|---|
| `EEPROM 저장` | 드라이브 지금 값을 전원을 꺼도 남게 (위 4번과 같음) | 그대로 사용 |
| `앱솔루트 방식` | Pr0.15 를 0~4 중 하나로 바꾸고 EEPROM 저장 (0 절대 · 1 인크리멘털 · 2 절대·넘침 무시 · 3 한 바퀴 · 4 연속 회전) | **드라이브 전원 재투입** → 모터 검색으로 값 확인 |
| `다회전 클리어` | 엔코더 회전 수 기록 지움 (0x4D01 = 0x0031 → 0x4D00:01 bit9) · **서보 OFF 일 때만** | **드라이브 전원 재투입 → 기준점 다시 캡처** · 그 전엔 재생 금지 |

셋 다 Motor Manager 를 몇 초 멈췄다가 다시 띄웁니다 (모터 검색과 같은 길) · 재생 중이거나 축이 움직이면 거절 ·
그 자리에 MINAS 가 실제로 있는지 확인한 뒤 씁니다 · 기록은 모터 이벤트(시스템)
