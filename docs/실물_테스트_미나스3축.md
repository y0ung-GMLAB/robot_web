# 실물 테스트 · 미니 PC 1대 + MINAS 3축 (2026-10-07)

- 대상 · main 최신(이 문서가 들어간 커밋 이후) · 미니 PC 1대 · MINAS 드라이브 3대 · 모터 3기(벤치 · 부하 없음)
- 범위 · `실물_확인_대기.md` 중 이 구성으로 되는 것 전부 + 엣지 케이스(E 번호) · PC 2대 연동(3장) · 다이나믹셀(4장)은 제외
- 결과 칸 · `확인됨` · `실패` · `검증 불가` 셋 중 하나 + 짧은 메모 · 실패는 화면 사진 · `journalctl --user -u <서비스> --since "10 min ago"` 저장
- 끝나면 결과를 `실물_확인_대기.md` 결과 칸으로 옮긴다(「확인 #」 열 = 그 문서 번호)

## 세션 안내 · 미니 PC 의 Claude Code 가 먼저 읽을 것

- 사용자와 같이 이 문서를 위에서부터 진행 · 사용자가 「실물 테스트 시작」 · 「N번부터」 라고 하면 그 단계부터
- 먼저 읽기 · 이 문서 · `docs/실물_확인_대기.md`(0장 포함) · `docs/수정_목록.md` · `AGENTS.md`
- 최근 바뀐 것(전부 **실물 미검증**)
  - 내부 단위 rad 전환(수정 목록 6) · 토픽·매핑·재생 rad · 화면만 deg · motor_manager 노드 경계에서만 deg ↔ rad
  - 알람 중 리셋 통과 · 알람 동안 받은 명령 버림(1) · 모터 노드 통신 루프 예외 → 종료 코드 70 → 서비스 자동 재기동(3-2)
  - 그룹 복귀(30-3 · 이 구성에선 시험 안 함) · 웹 3D 「실물 위치」(7-c) · 다이나믹셀 23·24·25(이 구성에선 시험 안 함)
- 개발 PC(윈도우)에는 ROS·컴파일러가 없었다 · C++ 은 문법 검사만 · ROS 쓰는 pytest 37건은 못 돌림 · **빌드·pytest 는 여기서 처음** (2장)
- 역할
  - Claude · 명령(갱신 · 빌드 · pytest · `journalctl` · 토픽·SDO 읽기 · 시험 애니 생성 · 프로세스 kill) · 결과 칸 기록 · 실패 원인 조사
  - 사용자 · 화면 클릭 · 케이블·전원 · 모터 눈으로 확인 · 비상정지 대기
- 규칙
  - **모터가 움직이거나 서비스를 멈추는 명령은 실행 전에 사용자 확인** · 읽기 전용은 바로(`.claude/settings.json` 의 ask/allow 그대로 · 자동 승인 모드 쓰지 않기)
  - `src/motion_system` 은 사용자가 명시할 때만 수정
  - 실패 · 로그(`journalctl --user -u <서비스> --since "10 min ago"`) 저장 → 원인 → 고칠지 사용자에게 묻기 → 고치면 테스트 추가 · 수정 목록 갱신
  - 결과 칸 · `확인됨` · `실패` · `검증 불가` + 짧은 메모 · 단계 묶음이 끝날 때마다 커밋(한국어 메시지) · push 는 사용자 확인 뒤
  - 끝나면 결과를 `실물_확인_대기.md` 결과 칸으로 옮기고 수정 목록 「실물 검증」 상태 갱신
- 자주 쓰는 것
  - 서비스 · `motion-control`(웹·supervisor 등) · `motion-motor`(motor_manager) · `systemctl --user status <이름>`
  - 시험 애니 · `python3 scripts/make_test_animations.py --out ~/test_anims` (조인트 `1-1` `1-2` `1-3` · A = 20°)
  - pytest · `source install/setup.bash` 뒤 저장소 맨 위에서 `python3 -m pytest` (`pytest.ini` 가 대상 폴더를 정함 · motion_system 제외)

## 0. 안전 · 준비

- 모터 축에 아무것도 달지 않는다(키 빼기 · 풀리·암 없음) · 모터 몸체는 고정 · 비상정지(차단기)가 손에 닿게
- 준비물 · 원격 노트북(같은 망 브라우저) · 여분 EtherCAT 랜선 · 이 문서 · 휴대폰(사진)
- 엔코더 커넥터를 뺐다 꽂을 수 있는지 확인(알람 유발용 · 드라이브 전원 끈 상태에서 빼고 켜면 Err21 류)
- 알람 유발 두 번째 방법 · 서보 ON 상태에서 손으로 축을 세게 잡고 조그(편차 과대) · 부하 없는 벤치에서만
- 시간 · 0~3장 1시간 · 4~12장 3~4시간 · 13장(장시간)은 밤새
